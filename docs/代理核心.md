# 代理核心与许可证

本项目通过 Xray-core 或 sing-box 承载 v2rayN 常见的 VMess、VLESS、Trojan、Shadowsocks 和 AnyTLS 节点。AnyTLS 使用 sing-box 的官方 outbound（Xray-core 当前内置版本不注册 AnyTLS）。v2rayN 本身是 GPL-3.0 的 .NET 桌面客户端，负责订阅、配置和核心编排；它不是可以直接作为 Electron JavaScript 依赖加载的库。因此应用参考其节点分组、订阅和表格交互，用自己的 Electron/HTML/CSS/SVG 实现，没有把 v2rayN 图形界面复制进来。

核心来源：

- v2rayN：<https://github.com/2dust/v2rayN>，GPL-3.0；
- Xray-core：<https://github.com/XTLS/Xray-core>，以其仓库发布的许可证和版权文件为准；
- sing-box：<https://github.com/SagerNet/sing-box>，以其仓库发布的许可证和版权文件为准；
- 官方发布页：<https://github.com/XTLS/Xray-core/releases>、<https://github.com/SagerNet/sing-box/releases>。

当前 Windows x64 构建已将 Xray-core 和 sing-box 官方二进制放在 `vendor/cores/win32-x64/`，版本、SHA-256 和第三方许可证见该目录的 [`README.md`](../vendor/cores/README.md)。节点表格中的“核心”列可以逐节点选择 Xray 或 sing-box；AnyTLS 节点固定显示 sing-box，避免误用不支持该 outbound 的 Xray。设置页的默认核心用于新导入的核心节点，已有节点仍保留自己的选择。其他平台暂未随源码提供二进制，需要在设置页指定已审计的本地核心或使用官方发布更新。

设置页的“在线安装 / 更新”只访问上述 GitHub 官方地址，下载当前平台压缩包和官方 digest（Xray 使用 `.dgst`，sing-box 使用 release asset digest），校验 SHA-256 后再解压。核心只监听 `127.0.0.1`，每个 profile 使用独立端口。节点密码、UUID 和 REALITY 参数不会发送到界面或日志；运行核心时会写入本机临时配置，停止 profile 后删除。应用不会下载或嵌入 v2rayN 的 .NET GUI。

更新后的核心版本与来源信息保存在用户数据目录，不应提交到公共仓库。发布安装包时，需要同时提供对应的第三方许可证和版权声明。
