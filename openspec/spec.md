# Chrome Profile Browser MVP 规范

## 目标

提供一个本地优先的 Chromium 工作台，用于合法的隐私、兼容性和自有站点测试：

- 每个环境拥有独立的持久化浏览器存储；
- 连接模式可以是系统直连、HTTP/SOCKS5 节点，或由内置 Xray-core / sing-box 转换为本地 SOCKS5 的常见 v2rayN 节点；
- 节点既可以从订阅导入，也可以在界面手动填写 HTTP、HTTPS 或 SOCKS5 的服务器/IP、端口和可选凭据；TLS、SNI、remote DNS 作为受限元数据保存；
- 可以从订阅地址导入常见节点格式；不支持的协议保留在订阅统计中，并在对应订阅源分组中保留查看，但从“全部”、手动分组和连接选择器隐藏，VMess、VLESS、Trojan、Shadowsocks 节点可按节点选择 Xray-core 或 sing-box 处理，AnyTLS 节点固定由 sing-box 处理；
- 订阅源会在本机保存，可手动在线刷新；成功获取新节点后直接覆盖该订阅的旧节点，刷新失败时保留上一份成功配置；
- 订阅导入优先识别响应头中的流量、到期和重置信息，并回退识别常见提示行；这些提示行不作为节点或连接选择项，订阅区域显示汇总统计；
- 可以直接加载未打包插件文件夹，或从 ZIP/CRX 导入 Chromium 插件，也可以输入 Chrome Web Store 详情页地址或 32 位扩展 ID 安装公开插件；插件管理页还可以搜索 CRX Soso 的 Chrome 扩展、查看详情并按受控扩展 ID 安装，并为每个环境单独选择激活范围；运行中的浏览器工具栏可启停插件并与管理页同步；读取 HTTPS `update_url` 或由插件公钥确定 Chrome Web Store 官方端点自动检查更新，用户确认后可升级到最新版；插件管理页始终提供单个与批量更新入口，批量操作顺序更新全部已安装插件、单项失败后继续并汇总结果；无在线来源时更新本地目录代码，有在线来源时更新官方在线版本；
- 配置中心与内置浏览器壳的确认和输入操作使用与当前主题一致的应用内弹窗，统一提供标题、说明、取消和确认动作；删除类危险操作使用明确的危险色确认按钮，凭据长期保留确认由发起操作的窗口展示，不使用浏览器原生白色确认/输入窗口；
- 可以在环境运行前或运行中切换连接节点；切换会停止旧的本地核心实例并启动新的实例；
- 运行中的环境允许直接更新名称和启动网址：内置 Electron 窗口同步名称，当前页面不跳转，新网址用于后续启动；连接、授权身份、备注等其他配置仍需停止环境后修改；
- 默认使用 Electron 自带 Chromium，也允许用户指定已经自行审计的 Chromium 可执行文件；
- 桌面应用使用稳定的应用身份和共享实例锁；重复启动（包括带不同调试 `--user-data-dir` 的启动）直接唤起已有配置中心，不创建第二个应用主进程；Chromium 的 GPU、网络服务和页面 renderer 子进程仍遵循多进程模型；
- 设置页可以下载官方 Chrome for Testing 稳定版并安装为外部 Chromium，同时保留 Xray-core 与 sing-box 的官方更新入口；内置 Electron Chromium 随应用版本更新，不在运行中热替换；
- 已安装的外部 Chromium 会自动检查官方稳定版，发现新版本时在设置页提醒；内置 Electron Chromium 不单独提示，随应用版本更新；
- 内置 Electron profile 窗口在最小化或隐藏时关闭 Chromium 后台页面节流，以尽量保持页面和插件计时器运行；该设置会增加资源消耗，不改变 Manifest V3 Service Worker 的空闲回收规则，外部 Chromium 仍遵循自身策略；
- 用户关闭浏览器环境窗口时，先执行停止环境的完整清理流程并停止该环境的代理核心；外部 Chromium 进程自行退出时也会回收其托管核心；最小化或隐藏窗口不会停止环境；
- Windows x64 发布目录内置官方 Xray-core 与 sing-box，设置页支持选择默认核心、指定本地路径和从对应官方 release 在线更新；
- 应用启动后会自动检查已配置代理核心的官方 release，发现新版本时在管理页提醒用户；检查失败不影响现有核心运行；
- 节点管理页采用 v2rayN 风格的分组、订阅和表格信息架构，所有工具图标使用项目自有 SVG；
- 订阅源面板采用统一深色卡片风格；订阅卡片显示总节点、可用节点和不支持节点数量，不显示内部排序号；订阅记录保存非负整数 `sortOrder`，支持编辑、上下移动和空白区域拖拽排序，排序顺序同步到节点分组与环境连接选择器；
- 节点表显示地址、国家/来源/属性摘要与 IP 地址、核心和状态；摘要位于 IP 上方并以“国家·来源·属性”排列，两行均居中；元信息自然宽度小于 IP 时，只扩展国家/来源和来源/属性之间的间距至与 IP 行同宽，元信息更宽时保持自然宽度，IP 始终使用正常字距。来源与属性去掉末尾“IP”，未查询项明确显示“未查询”；广播来源优先显示红色，其他机房属性显示橙色，住宅属性显示绿色，仅识别到原生来源时显示青蓝色；国家/来源/属性与 IP 均在列内截断，不得覆盖相邻列；
- 节点“全部”和手动分组隐藏明确不可用的节点，订阅源分组显示该订阅返回的全部节点（包括不可用和不支持的节点），未检测节点保留以供检查；环境编辑表单与连接下拉只允许选择最近检查可用的节点，已有环境当前选中但变为不可用的节点在编辑时保留现有值，连接下拉按直连、订阅源和手动节点独立分组切换，候选行按国家·来源·属性在上、IP 地址在下显示并带最近连通性状态/延时；系统直连有出口信息时采用相同布局，无信息时保留“系统直连”；候选提供闪电图标重测节点或直连，明确失败的节点从候选中移除；
- 环境列表的连接选择器保留搜索，并按直连、订阅源和手动节点分组切换；节点候选行按国家·来源·属性在上、IP 地址在下显示，来源和属性值去掉末尾“IP”；系统直连信息可用时也按两行显示；当前连接的连通性与最近延时仍显示在环境列表；订阅源列表支持搜索和独立滚动；
- 环境列表可直接测试当前选中的连接，测试结果复用对应节点或直连的状态与延时；代理环境的 WebRTC 不得通过非代理 UDP 暴露本机地址；
- 环境列表和启动器的 IP 信息通过当前连接的 IPPure 出口探测显示两行：上行为国家、IP 来源和 IP 属性，以“·”分隔且来源/属性值去掉末尾“IP”；两行均居中，元信息较短时只扩展国家/来源、来源/属性间距至与 IP 行同宽，元信息较长时保持自然宽度，IP 使用正常字距。广播来源优先显示红色，其他机房属性显示橙色，住宅属性显示绿色，仅识别到原生来源时显示青蓝色。未返回的值显示“未查询”，不显示节点地址、协议或连通性摘要；点击信息区域仍可打开按节点、地址或订阅搜索的连接选择器并切换当前连接；连接选择项和订阅源节点行采用相同的两行布局，IP 地址保留在元信息下方；
- 每个环境在成功启动后保存当时探测到的公开出口 IP；下次启动前重新探测当前连接，IP 相同或缺少任一有效 IP 时直接启动，IP 不同时先提示上次 IP 并要求用户再次确认，取消时不启动且不覆盖上次 IP；
- 每个环境独立统计内置 Electron profile session 的上传、下载和总使用流量，运行期间更新并持久化到本地；外部 Chromium 没有可观测计数时只显示已保存累计值；
- 所有 profile、节点、订阅和设置默认保存在本机，不提供云端同步。
- 配置中心提供按浏览器环境隔离的本地密码簿，可新增、编辑、删除和搜索服务账号记录；列表按 HTTP(S) origin 分组并可展开账号，地址缺失或无效的旧记录按服务名分组，工具栏在桌面宽度保持单行。收起的网站行显示首个账号、对应的掩码密码和账号数量，密码框悬停或键盘聚焦时显示真实值，移开且失焦后立即清除并恢复掩码。每条记录固定属于一个环境，主进程校验保存、编辑、删除和密码读取的环境归属，删除环境时同步删除其记录。密码保存在本机状态文件并优先通过 Electron `safeStorage` 加密。公共状态只包含环境编号及服务、账号、地址和备注等非密码字段，查看密码时由主进程按环境和记录单独提供。
- 内置 Electron 浏览器的 HTTP/HTTPS 登录页可以按当前网页 origin 查询当前环境的密码簿候选，在网页内悬浮弹窗中选择账号并按需填充密码；提交带账号和密码的表单后显示与应用主题一致的保存提示，同一环境、origin 和账号已存在时提示“更新”并在确认后更新现有密码记录，否则新增记录。取消、点击外部、超时或导航后关闭提示。
- 面向自有或获授权测试站点，可为每个 profile 保存稳定的测试身份 UUID，并仅向用户明确列出的精确 HTTP(S) origin 添加 `X-CPB-Test-Identity` 请求头；该身份不等同于设备 ID 或浏览器指纹。
- 浏览器工具栏提供网页助手入口和右侧对话栏，可在当前 profile 内读取信息、收集链接/表格、管理标签、导航网页并执行滚动、点击、填写、下拉选择以及虚拟鼠标/键盘动作；动作由固定模板和白名单协议执行，不接受任意脚本。用户通过系统选择器明确授权后，Agent 还可以列出受限文件夹条目、读取文本文件并把授权文件设置到当前网页的 `input[type=file]` 控件；授权仅在当前 profile 运行期间有效，完整本地路径不返回给远程模型。内置浏览器 profile session 开放网页权限、设备能力、下载和屏幕捕获，并把网页新窗口放入当前标签栏。Agent 快捷设置保留在对话页右上角；独立 Agent 配置页提供全局 Agent/JEV 配置、环境作用域和单环境覆盖，可接入 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Gemini，并配置上下文、输出、温度和工具步骤上限。
- 网页助手的四种协议支持流式文本输出；等待页面观察或模型响应时对话框显示思考动画，首开面板显示欢迎语。普通聊天直接显示为文本气泡，工具调用显示为带中文名称、执行状态和可展开结果的动作卡片；闲聊和一般问题不强制调用工具。
- 检测到疑似人机验证时，网页助手把状态放入观察结果并提示用户；不会自动暂停远程 Agent 动作，用户可以随时停止任务。
- 浏览器环境窗口提供贴合窗口最上方的横向多标签栏；标签可新建、切换、关闭，并可通过拖动改变同一窗口内的顺序。标签栏关闭图标在悬停或键盘聚焦时显示，空闲时隐藏且保留固定宽度，减少误关。活动标签高亮随切换平滑移动，新标签进入和重排有短暂过渡；拖动时被拖标签跟随指针，相邻标签以平滑位移动画让位，松开后顺序保留在当前运行会话中；按 Escape、指针取消或窗口失焦后恢复原顺序。每个标签独立保留地址、标题与页面历史。标签栏最前面的列表按钮打开可搜索的标签面板，显示当前打开标签和当前窗口最近关闭的最多 20 个网页标签；可切换、单独关闭或重新打开，最近关闭记录不跨窗口或应用重启保存。支持 `Ctrl+T`、`Ctrl+W`、`Ctrl+Tab`、`Ctrl+L` 和 `Ctrl+Shift+A`（打开/关闭标签面板）。系统启用减少动态效果时关闭装饰性过渡。Windows/Linux 使用原生窗口控制叠加，标签空白区域可拖动窗口。
- 浏览器连接区域显示当前节点的国家和 IP；节点检查成功后优先使用通过当前节点探测到的公网出口 IP 与国家，探测失败时回退到节点元数据或最近一次值，未解析的域名明确标记为待解析。
- 新建标签按钮紧邻最后一个标签，后面提供图标化的浏览器设置入口；新标签地址栏为空，普通文字按可配置搜索引擎模板查询（默认 Google），HTTP(S) 地址或域名直接打开；新标签页搜索框可显示当前环境最近搜索建议，输入搜索词时隐藏常用网站入口并保留 Banner 与搜索栏。
- 内置浏览器启动、加号和 `Ctrl+T` 都进入可配置的新标签页；新标签页提供常用搜索引擎、常用网站入口和支持图片/GIF/视频或网络地址的 Banner。常用网站入口按浏览器环境自动记录本应用内成功提交的顶层 HTTP(S) 网站访问，同一主机至少访问两次后推荐，90 天未访问的记录过期，自动入口最多六个并排在手动入口前；与手动入口主机重复时只显示手动入口，清除该环境浏览数据时清理自动记录，详见 [`smart-new-tab-sites`](specs/smart-new-tab-sites/spec.md)。
- 网页请求新窗口或 `target=_blank` 时由浏览器壳创建新标签，拒绝脱离当前环境的额外窗口。
- 浏览器设置支持自定义刷新和开发者工具快捷键，以及启用状态、鼠标按键、方向序列、动作和距离的鼠标手势；默认 `F5` 刷新、`F12` 开发者工具，右键“右滑 → 左滑”后退一页；网页助手可通过受控工具辅助保存这些设置。
- 配置中心支持窗口级界面缩放，内置浏览器壳的左 Ctrl+滚轮只缩放当前网页 guest：向上按 10% 放大、向下按 10% 缩小，范围为 50% 至 200%；左 Ctrl+0 恢复 100%。浏览器壳的标签栏、地址栏和工具栏保持原尺寸，每个窗口单独从 100% 开始且不持久化；右 Ctrl 不触发。缩放后在当前网页右上角显示最新百分比，最后一次操作约 2.5 秒后自动消失；外部 Chromium 不在此功能范围内。
- 配置中心启动浏览器环境后自动隐藏到系统托盘；左键双击托盘图标恢复配置中心，右键菜单提供展开和退出，悬停提示显示当前运行中的浏览器数量和名称；隐藏配置中心不停止浏览器环境或代理核心。
- 浏览器工具栏提供按 profile 保存的 HTTP(S) 收藏；收藏按钮固定在地址栏右侧，未收藏时显示空心 `☆`，已收藏时显示 `⭐`，不随焦点改变位置；地址栏聚焦或输入时可以从收藏、最近访问、匹配地址和搜索关键词中选择快捷项，失去焦点或点击其他区域后收起建议列表；编辑 HTTP(S) 地址时隐藏协议前缀，向左拖动到文本起点后显示并支持选择完整地址；
- 内置浏览器右键菜单遵循 Chrome 常见的页面、链接、编辑、图片和媒体操作；普通链接在当前标签打开，`target=_blank`、`window.open`、Ctrl/中键等新窗口请求进入当前 profile 的新标签栏；视频和音频使用 Chromium 原生播放控件，并可从媒体菜单直接下载，工具栏下载管理显示任务进度并支持取消、打开文件和清除已完成记录；网页助手使用独立于地址栏的 SVG `AI` 工具栏按钮，始终可用且不会与收藏按钮重叠；
- 浏览器工具栏可查看本机当前 TCP `LISTENING` 地址和端口；每次打开面板或手动刷新时从 Windows 当前状态重新读取，通配绑定地址提供回环地址，点击地址可按所选 HTTP/HTTPS 方式在当前标签打开；
- 收藏栏位于地址工具栏下方，默认只在新标签页显示；`Ctrl+Alt+D` 可切换为所有页面显示，收藏链接优先显示网页图标，缺失时尝试网站根路径 `/favicon.ico` 并在失败后显示默认图标；文件夹可嵌套并点击展开；空白处右键可添加当前页面或新建文件夹，链接右键可在当前/新标签打开、编辑标题与地址或删除，文件夹右键可新建内容、重命名或删除，非空文件夹删除前确认并递归清除内容；收藏和层级按 profile 保存，旧收藏继续作为根目录链接显示。
- 浏览器扩展弹层按当前环境的启用状态分组显示插件；每项可独立固定到该环境的工具栏，已固定且已启用的插件显示为快捷图标。更多选项可查看简介、版本、网站访问范围和请求权限，并在当前环境启用或停用插件；面板底部提供插件管理入口。插件详情只展示清单声明的权限，不代替 Chromium 的网站授权流程。
- 节点表中的订阅节点可以编辑和查看详情，双击节点行打开详情；编辑时保留原协议、核心配置与订阅归属，用户明确要求时在本地编辑表单回显用户名和密码，不写入日志或诊断；
- 浏览器设置保留搜索引擎配置；Agent 的协议、接口地址、模型、上下文、输出、思考等级、温度、步骤和受保护 Token 可在对话页右上角快速配置，也可在独立 Agent 配置页保存全局默认或环境覆盖。思考等级提供 `Off`、`Minimal`、`Low`、`Medium`、`High`、`XHigh`、`Max`，模型不支持所选等级时按相邻等级自动降级。模型字段支持按协议拉取列表，配置页提供图标化连通性测试。Token 不得进入公共状态，长期保存前必须得到用户确认。
- 浏览器导航、打开、插件、网页助手和状态入口使用图标按钮并保留无障碍名称；浏览器环境窗口不显示 Electron 原生菜单栏文字。
- 产品版本使用三段式版本号；每次变更只递增一个层级，小功能更新号按 `010` 递增，普通更新号按 `001` 递增，上级递增时下级归零。
- 浏览器引擎设置必须在保存时校验路径；运行中的环境禁止静默切换引擎，界面显示当前是 Electron 还是外部 Chromium 以及两者数据不互通的边界。
- Windows x64 发布包必须把代理核心放在安装资源目录，安装后不得依赖源码工作区。

## 明确不做

- 不注入 JavaScript 修改 Canvas/WebGL/TLS，不实现验证码、风控或封禁绕过；
- 不复制或嵌入 v2rayN 的 .NET 图形界面；应用只参考其交互信息架构，并集成 Xray-core 与 sing-box 的运行链路。Windows x64 内置核心来自对应官方 release，随版本清单、SHA-256 和许可证文本一起发布；设置页也允许用户一键触发官方 release 下载、校验和安装，显示当前与可更新版本，成功后立即反映实际安装版本；其他平台未随源码提供二进制；
- 本版本支持 VMess、VLESS、Trojan、Shadowsocks 的常见 TCP/TLS、WebSocket、gRPC、REALITY 参数，以及 sing-box AnyTLS 的 TLS、SNI 和证书校验参数。未知传输或不完整字段必须保留为不支持记录，不得静默降级；
- 不把“直连”描述为绑定某个公网出口 IP。直连使用系统默认网络路径，特定出口需要操作系统路由/VPN。
- 不为任意网站伪造或随机化浏览器指纹；授权测试身份只通过来源白名单请求头提供。
- Agent 可以向用户配置的远程模型发送当前对话和受限观察结果，并按模型返回的工具调用循环执行；Agent 默认配置可在插件管理中作用于全部或指定环境，也可为单个环境保存覆盖。页面操作必须经过动作白名单，且仅作用于当前页面视图；普通网页是 `<webview>` 顶层文档，内置 `about:newtab` 是受控的新标签页区域；虚拟输入不触碰操作系统级其他窗口。

## 已知限制与安全边界

- 默认引擎是 Electron 自带的 Chromium。Electron 模式的默认 User-Agent 可能包含 `Electron/<version>`，系统不承诺提供纯 Chrome User-Agent，也不伪造 Canvas、WebGL 或 TLS 指纹。
- 代理启动参数只包含协议、地址和端口。解析时保留的 `sni`、`remoteDns`、`udp`、`skipCertVerify` 等字段不保证会被 Chromium 的代理配置消费；`socks5h` 输入在浏览器侧按 SOCKS5 使用。节点检查对 TLS/SNI 或 SOCKS5 认证的结果，仅表示检查链路的 TCP/协议握手状态。
- Electron 可以尝试响应代理认证请求，但 SOCKS5 用户名/密码认证的 Chromium 兼容性有限；外部 Chromium 启动不会自动填充代理凭据。
- Electron 的代理配置包含 `<local>` bypass 规则，匹配该规则的本地主机名等地址可能绕过代理节点。
- 外部 Chromium 代理启动时接收独立用户数据目录、`--proxy-server`、`--disable-quic` 和 `--force-webrtc-ip-handling-policy=disable_non_proxied_udp` 参数；Electron 模式对宿主与每个 webview guest 设置同等 WebRTC 策略。最终行为仍受浏览器版本和代理是否支持 WebRTC UDP 影响。
- 授权测试身份仅在内置 Electron profile session 中生效：精确 origin 的非预检请求会附加 `X-CPB-Test-Identity`；外部 Chromium 不注入该请求头。该机制不改变 UA、Client Hints、Canvas、WebGL、Audio、字体、屏幕、硬件参数、TLS 或 WebRTC 指纹。
- Electron 44 对包含 `<webview>` 的窗口关闭存在阻塞风险。停止环境时先通过 shell renderer 移除页面 guest，再在有界等待内销毁外层窗口；若 Electron 没有及时关闭，应用退出时仍会统一回收。
- 正常生命周期会回收托管的外部 Chromium 和代理核心；主进程被强制终止或崩溃后，不承诺跨重启自动发现并接管遗留进程。
- 手动节点凭据、UUID 和核心配置中的密钥优先使用 Electron `safeStorage` 加密；操作系统密钥环不可用时允许降级为本地明文保存，因此必须保护数据目录和操作系统账户。为保证重启后可刷新，订阅地址和订阅导入节点配置按本地明文保存；诊断和日志不得输出这些值。
- 密码簿记录仅保存在本地并按浏览器环境隔离；密码优先使用 Electron `safeStorage` 加密，系统加密不可用时与现有敏感数据策略相同，回退为本地明文并依赖操作系统账户和数据目录保护。密码不进入公共状态或日志，只在指针悬停、密码框获得焦点或用户确认网页登录保存时短暂进入 renderer；指针移开且字段失焦后清除，保存提示关闭后清除。
- 保存手动节点识别到账号、密码、UUID 或核心密钥时，必须先征求是否长期保留；订阅导入不再对订阅 URL 或订阅节点密钥加密保存，拒绝长期保留的手动节点仍可导入但敏感字段不落盘。
- 出口 IP 探测仅接受公开 IP 并持久化；未命中出口结果时的地理回退查询按 IP 去重，IPPure 不可用时回退到 ip111.cn，探测失败不影响节点检查，代理服务器 IP 不等同于代理出口 IP。
- 多标签使用同一 profile 的持久化 session；各标签的页面历史和导航状态独立，移除标签时不得影响其他标签。
- 插件仅从用户明确选择的本地目录、压缩包或 Chrome Web Store 来源加载；Electron session 只接受 Manifest V2/V3 的解压目录，本地更新会重新读取并重载运行中的 Electron 插件，外部 Chromium 的插件变更在下次启动时生效，正在使用的旧解包副本会在进程退出后清理。
- 插件安装和更新只接受 HTTPS 官方清单和包地址；Chrome Web Store 发现与安装只接受官方商店主机和合法扩展 ID，搜索和详情读取官方公开页面，安装通过官方 CRX 更新端点下载；CRX Soso 继续作为聚合发现来源，安装只接受合法 Chrome 扩展 ID，并将下载地址限制在 CRX Soso 的 HTTPS CDN；商店搜索、详情和安装请求允许单独选择系统直连或已有节点，官方 Chrome Web Store 打开时默认从已检查可达的节点中随机选择一个，没有可达代理时不得静默回退到系统直连；节点选择使用可搜索的分组行列表，切换发现页线路后重新加载当前搜索结果，HTTP/HTTPS、SOCKS5 与核心托管节点请求均在主进程中代理，不改变浏览器环境连接设置；自动检查不等于静默安装，安装或更新包必须先通过 manifest、名称、版本和（可用时）扩展身份校验，再替换旧版本。
- 核心实例只监听 `127.0.0.1`，每个 profile 使用独立的临时端口和配置文件；核心退出、配置校验失败或端口冲突时，profile 启动必须失败并清理子进程。
- 本地服务入口显示受支持前端开发服务器，以及根路径通过受限本机 HTTP/HTTPS 检查并成功返回 `text/html` 的 Windows TCP 服务；关联 PID、进程命令行和项目 `package.json` 排除不提供网页的系统服务和后端 API。同一项目同一端口的多地址绑定合并显示。项目名优先使用 `package.json` 的 `name`，缺失时回退可执行文件所在目录或进程名。探测只访问本机监听地址、不跟随重定向、设置超时与并发上限，不读取完整响应；用户选择 HTTP 或 HTTPS 后点击列表地址在当前标签导航，不保存或分享端口清单。
- 本项目的“节点检查”只验证 TCP 可达性及选定协议的握手，不承诺目标站点可访问、出口 IP 固定或能绕过站点策略。
- 代理环境必须在 Electron 的宿主与 webview guest 上使用 `disable_non_proxied_udp`，外部 Chromium 代理启动时使用等价的 WebRTC 策略并禁用 QUIC；直连环境可恢复默认 WebRTC 策略。
- 环境列表会显示所选连接的最近状态与延时；应用运行期间启动后立即检查并每 60 秒自动检查一次，未被环境使用的节点仍可手动检查。普通代理显示 TCP/代理握手延时，核心托管节点启动隔离核心并通过本地 SOCKS5 代理握手后才显示可达，延时从核心启动开始计至目标握手完成。
- 节点管理页支持对当前分组和搜索筛选结果执行批量检查；任务限制并发，单个节点失败不会中断其他节点。
- 网页助手入口可打开或关闭右侧面板；面板能同步当前页面标题和地址，快捷动作、明确选择器指令以及观察/虚拟输入动作返回受限大小的页面结果或可读错误。动作卡片显示实际动作及关键参数，如坐标、滚动方向与距离、按键组合；输入文本不出现在动作标题中。`window.browserAgent` 和 preload bridge 仅暴露观察、白名单动作和批次执行接口。
- 虚拟输入 bridge 只绑定内置 Electron 引擎的活动页面视图；普通网页使用 `<webview>`，内置 `about:newtab` 使用受控的新标签页区域。外部 Chromium 由独立进程运行，不提供该窗口控制能力。
- 人机验证状态只作为页面观察信息，不调用第三方代解服务；用户可以停止 Agent、切换标签或关闭环境。
- 远程 Agent 请求只在主进程发出，Token 从安全存储读取且不返回 renderer；请求有超时、大小和消息数量限制。Responses 的 `function_call` 与 `function_call_output`、Anthropic 的 `tool_use`/`tool_result` 和 Gemini 的函数调用必须保持调用 ID 配对；上下文裁剪不得拆开工具调用组。
- 远程 Agent 流式事件只向对应 profile 的 renderer 发送文本增量和已解析结果；不支持流式的接口回退为一次性响应解析。
- Agent 步骤上限为非负整数，`0` 表示持续执行；用户可通过发送按钮中止当前循环。JEV 使用 TypeSafe System One provider，支持官方 Key 与自定义兼容端点；网页任务的每批动作后由 JEV 判断是否完成，并显示判断状态、置信度和理由。未完成时 Agent 继续循环，完成时生成最终总结；普通闲聊不触发自动判断，显式 `jev_decide` 仍可按需调用。
- Agent 模型、JEV 和可安全重放的页面操作遇到瞬时失败时按 1、2、4、8、16 秒间隔最多重试 5 次；用户停止或窗口关闭会取消等待。点击、提交、上传等动作若结果不确定则先重新观察，不盲目重放；步数上限、停止或 JEV 不可用时明确标记未得到完成确认。
- 外部 Chromium 的启动必须等待进程成功创建；启动错误、立即退出、核心异常退出和停止超时都必须有明确状态，并且停止超时时不得删除仍被占用的数据目录。

## 可验证成功标准

1. 启动桌面应用后可创建、编辑、删除 profile。
2. 启动同一 profile 两次时，Cookie/localStorage 等数据保持；不同 profile 之间互不共享。
3. profile 可以切换直连、HTTP/SOCKS5 节点，或一个由 Xray-core/sing-box 托管的 VMess/VLESS/Trojan/Shadowsocks/AnyTLS 节点；AnyTLS 使用 sing-box。
4. 订阅导入支持 HTTP(S) 文本、base64 URI 列表和常见 Clash `proxies` YAML；未知协议被标记而不是静默丢弃；订阅源可在线刷新。
5. Windows x64 可直接使用随项目提供的 Xray-core 和 sing-box；设置页可对两者执行官方 release 更新并校验，更新安装支持官方压缩包的完整解压内容并显示实际版本，核心实例只暴露本地 SOCKS5 端口。
6. 节点检查只报告 TCP/协议握手可达性，不宣称能绕过任何站点策略。
7. 关键解析、两种核心的配置生成与生命周期、持久化和 IPC 输入校验有自动化测试；主界面和浏览器工具栏不依赖 Unicode 图形字符。
8. 插件可直接加载未打包文件夹、导入压缩包或从 Chrome Web Store 安装，按环境独立激活、在浏览器工具栏启停，并在管理页自动反映最新状态；不同环境可以拥有不同插件组合，修改一个环境不会覆盖其他环境。
9. 插件管理页能从 Chrome Web Store 详情页地址或扩展 ID 安装公开插件，也能搜索 CRX Soso 的 Chrome 扩展并查看详情后按扩展 ID 安装；商店请求可通过可搜索的节点行列表单独选择直连或已有代理节点，发现页切换节点后重新加载当前结果且旧请求不能覆盖新线路结果，不改变 profile 的浏览器连接；也能自动检查声明的官方更新地址或可验证的 Chrome Web Store 官方端点，并在用户确认后完成在线版本升级；没有在线来源时，更新按钮重新读取本地目录并应用代码，失败时报告明确原因。
10. 环境列表的连接列显示状态与毫秒延时；应用启动后和每 60 秒能自动更新环境实际使用的普通节点与核心托管节点，失败时显示可辨识的失败状态；节点页可批量检查当前筛选结果并显示汇总。
11. 环境列表和启动器显示每个环境独立累计的上传、下载和总使用流量，停止或重启应用后统计值保持；无法观测的外部 Chromium 流量不伪造实时数值。
12. 环境连接选择器支持按节点、地址、协议或订阅名称搜索；订阅源数量较多时列表在局部区域滚动，不要求用户反复滚动整个页面；选择器弹层跟随触发项定位，在视口边缘自动调整展开方向和尺寸，并在滚动或窗口缩放后重新定位。
13. 应用界面和请求标识显示统一产品版本，版本更新命令能按规则同步并校验包元数据。
14. 在线订阅的剩余流量、到期时间和下次重置时间可从响应头或常见提示行识别并统计显示；提示行不出现在节点分组和环境连接选择器中，不支持节点只在对应订阅源分组中保留查看并从“全部”、手动分组和环境连接选择器中排除，订阅区域显示总节点、可用节点和不支持节点数量，节点表同时显示 IP 地址列。
15. 每个 profile 有稳定的测试身份 UUID；配置精确来源后，内置 Electron 仅向该 origin 的非预检请求添加 `X-CPB-Test-Identity`，其他来源不会收到；外部 Chromium 明确提示不支持该能力。
16. 关闭浏览器环境窗口后，该环境状态变为已停止并回收其代理核心；最小化或隐藏窗口不会停止环境。
17. 浏览器工具栏可打开网页助手面板；读取页面、收集链接/表格、管理标签、导航、滚动、点击选择器、填写选择器和下拉选择动作均可验证，且任意输入不会作为 JavaScript 代码直接执行。
18. 网页助手可捕获当前标签观察结果，并通过受控动作协议在当前 `<webview>` 内执行模拟人工的坐标鼠标、滚轮、拖拽、键盘组合和文本输入；坐标鼠标可操作页面任意位置，切换标签后不会操作后台标签，profile session 的网页权限和下载记录可被 Agent 使用。用户明确选择本地文件或文件夹后，Agent 可列出全部条目、读取文本文件全部内容，并通过 CSS 选择器把任意数量的已授权文件设置到当前网页的 `input[type=file]`；文件能力不设置应用层数量、深度、大小或批次上限，授权不写入状态文件，profile 停止后失效。
19. 浏览器环境窗口可新建、切换和关闭多个标签；关闭图标只在标签悬停或键盘聚焦时显示。标签栏首部列表面板能搜索标题/网址、切换或关闭打开标签，并恢复当前窗口最近关闭的网页标签；活动高亮平滑移动且新增/重排动效可见，减少动态效果设置会关闭装饰性动画。连接区域显示国家和 IP（域名未解析时有明确回退文案），工具栏操作使用图标且原生菜单文字隐藏；工具栏可保存收藏并从地址栏下拉项快速打开；检测到手动节点敏感字段时出现保留确认，长期保留后重启仍可使用认证字段，拒绝后状态文件不含该字段。
20. 新建标签页的地址栏保持空白；普通文字按设置中的搜索引擎模板打开，浏览器设置齿轮保存搜索引擎、常用网站、Banner 与收藏栏显示范围；新标签页默认使用全屏沉浸背景，可通过右上角图标切换简约指纹布局，搜索框在两种模式下均可用且新标签页支持刷新；常用网站会根据当前环境在本应用内近期访问自动更新，并保留手动维护功能，详细行为符合 [`openspec/specs/smart-new-tab-sites/spec.md`](specs/smart-new-tab-sites/spec.md) 和 [`openspec/specs/new-tab-display-modes/spec.md`](specs/new-tab-display-modes/spec.md)。Agent 对话页右上角的齿轮或独立 Agent 配置页保存协议、模型和 Agent Token；Token 只以安全存储形式持久化。
21. 节点检查成功后，应用能通过当前节点探测并显示公开出口 IP、国家、IP 来源和 IP 属性；IPPure 不可用时回退到 ip111.cn，探测失败不阻断节点检查，私有 IP 保持明确的未解析状态。
22. 外部引擎路径、官方 Chrome for Testing 浏览器内核安装、进程生命周期和 Windows x64 安装资源满足 [`openspec/changes/external-engine-and-packaging.md`](changes/external-engine-and-packaging.md) 的验证标准。
23. Agent 快捷设置位于对话页右上角，完整的全局/环境 Agent 与 JEV 配置位于独立 Agent 配置页；四种协议均能生成正确的认证头、请求路径、消息和工具格式，模型列表和连通性检查由主进程完成，OpenAI Responses 能解析文本与 `function_call` 并回传 `function_call_output`；Agent 思考等级提供七档配置，OpenAI 协议携带对应字段，当前模型不支持所选等级时自动退到可用的相邻等级；上下文裁剪保持工具调用组完整，Token 不出现在 renderer 公共状态中。
24. 应用会检查已配置代理核心和外部 Chromium 的官方版本，发现新版本时提醒；设置页明确显示核心当前版本与可更新版本，一键更新成功后当前版本随安装结果变化；订阅成功获取新节点后直接替换该订阅的旧节点。
25. 订阅编辑和排序号保存后，订阅源、节点分组和环境连接选择器保持相同顺序；旧订阅缺少排序号时按原顺序从 0 开始迁移，非法排序号不能通过主进程校验。
26. 浏览器环境默认响应 `F5` 刷新、`F12` 开发者工具和右键“右滑 → 左滑”后退；快捷键和鼠标手势设置保存后跨重启生效，非法配置不能写入状态；网页助手可以通过白名单工具提交配置。
27. 浏览器环境启动后配置中心隐藏到系统托盘；双击托盘图标可恢复，右键菜单可展开或退出，悬停提示能显示正在运行的浏览器数量和名称；托盘隐藏不会停止环境，退出仍执行统一清理。
28. 检测到疑似人机验证时，网页助手把标记放入观察结果并显示提示，不自动暂停远程 Agent 页面动作；用户可以停止当前任务。
29. 网页助手支持流式文本、思考动画、首开欢迎语和自然聊天；工具调用与普通回答使用不同的动作卡片和文本气泡展示，四种协议的流式响应在不支持时可回退解析。
30. 浏览器右键菜单、链接新标签、媒体下载和下载管理符合 [`openspec/changes/browser-context-menu-media-downloads.md`](changes/browser-context-menu-media-downloads.md) 的验证标准；Agent 入口位于地址栏外侧并使用 SVG `AI` 标识，收藏星标固定在地址栏内侧。
31. 配置中心密码簿可为选定浏览器环境新增、编辑、删除和搜索服务账号记录；按网站 origin 显示可展开分组，收起行显示首个账号、对应的掩码密码和账号数量，窄屏工具栏与分组行可自适应布局；切换环境后只显示其记录，跨环境编辑、删除或读取密码会被主进程拒绝，删除环境时清理其密码记录；重启后记录仍存在，状态推送不含密码明文，密码默认掩码，鼠标悬停或键盘聚焦时显示，移开且失焦后清除并恢复掩码。
32. 应用使用稳定的单实例锁校验启动；第二次启动直接恢复并聚焦已有配置中心，重复启动已运行环境返回已有实例且不增加浏览器或代理核心进程；Electron/Chromium 的正常 GPU、网络服务和 renderer 子进程不被误判为重复应用。
33. 浏览器工具栏显示可识别的前端开发服务器和根路径符合成功 `text/html` 响应条件的本机 TCP 端口，并在地址右侧显示项目名；纯 API 和非 HTTP 服务不显示，同项目同端口的多地址绑定合并，计数与可见项目端口一致；通配绑定地址提供可点击的回环访问地址，HTTP/HTTPS 均能在当前标签中导航，有限超时下扫描可完成，空列表和查询错误有明确提示；每条服务提供停止图标，点击后必须二次确认，主进程重新校验 PID、端口和项目名后才能停止对应进程树，成功后刷新列表。
34. 环境启动前通过当前直连或节点检查出口 IP；与该环境上次成功启动 IP 一致时直接启动，不一致时显示当前 IP、上次 IP 和建议并要求二次确认；取消不会启动或更新上次 IP，确认继续后浏览器启动且记录更新；缺少有效探测结果时不阻断原有启动流程。
35. 配置中心从 100% 独立缩放；内置浏览器壳左 Ctrl+滚轮上滚/下滚只调整当前网页 guest，按 10% 调整且限制在 50%–200%，左 Ctrl+0 恢复 100%，浏览器壳标签栏、地址栏和工具栏保持原尺寸，右 Ctrl 不触发；右上角提示反映最新比例并在最后一次操作约 2.5 秒后隐藏，外部 Chromium 不受影响。
36. 网页助手动作标题显示动作和关键参数；瞬时失败按退避间隔最多自动重试 5 次且可取消，不重复执行结果不确定的非幂等动作；每批网页动作后由 JEV 判断并展示完成状态、置信度和理由，未完成时 Agent 继续，完成时输出总结，无法判断或达到步数上限时不宣称完成。
37. 运行中的环境可保存名称和启动网址而无需关闭；配置中心立即显示新值，内置 Electron 窗口同步名称，当前页面保持不变且下一次启动使用新网址；运行中修改连接、授权身份、备注或其他配置仍被拒绝；外部 Chromium 进程保持运行。
