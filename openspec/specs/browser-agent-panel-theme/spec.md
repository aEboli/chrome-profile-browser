# browser-agent-panel-theme Specification

## Purpose
确保网页助手的浏览器设置、对话、表单和状态提示在浅色与深色主题下都使用匹配且可读的颜色，并让背景、文字、边框及反馈状态随主题切换同步更新。

## Requirements

### Requirement: 网页助手全部面板跟随选择的主题

网页助手的浏览器设置面板、人工验证提示、对话表面、表单控件和状态样式 MUST 使用当前 Agent 面板的深浅主题语义颜色。切换主题 MUST 同步更新背景、文字、边框、控件和提示表面，且文字与背景保持可读对比度。

#### Scenario: 浅色主题显示浏览器设置

- **WHEN** 用户选择网页助手浅色主题并打开浏览器设置面板
- **THEN** 设置面板、分区标题、表单输入、保存栏和边框均显示浅色主题配色
- **AND** 不残留夜间模式的深色面板或浅色正文文字

#### Scenario: 浅色主题显示人工验证提示

- **WHEN** 网页助手在浅色主题下提示用户完成网页人工验证
- **THEN** 提示背景、正文和操作控件使用浅色兼容配色
- **AND** 提示等级和操作按钮仍保持清晰可辨

#### Scenario: 切回深色主题

- **WHEN** 用户将网页助手切回深色主题
- **THEN** 所有相关面板、控件和提示恢复为深色主题配色
