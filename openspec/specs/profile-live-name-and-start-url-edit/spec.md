# profile-live-name-and-start-url-edit Specification

## Purpose
定义浏览器环境在保持运行时修改可即时生效的名称与启动网址，并明确这些元数据变更不得重定向当前页面，以及连接和其他运行时配置所需的停止边界。

## Requirements

### Requirement: 运行中环境可编辑名称和启动网址

系统 MUST 允许用户在环境运行时修改并保存环境名称或启动网址，而无需关闭环境。保存后，管理界面 MUST 立即显示新值；启动网址 MUST 用于后续启动，且不得强制改变当前打开的网页。

#### Scenario: 更新运行中环境的名称
- **WHEN** 用户在运行中的环境编辑表单中修改名称并保存
- **THEN** 保存成功，管理界面和内置 Electron 环境显示新名称，环境继续运行

#### Scenario: 更新运行中环境的启动网址
- **WHEN** 用户在运行中的环境编辑表单中修改启动网址并保存
- **THEN** 保存成功，当前网页保持不变，下一次启动该环境时使用新网址

#### Scenario: 运行中提交其他配置变更
- **WHEN** 用户在运行中的环境同时修改名称或启动网址之外的环境配置
- **THEN** 保存被拒绝并提示先停止环境，原配置保持不变

#### Scenario: 外部 Chromium 环境更新元数据
- **WHEN** 用户在由外部 Chromium 运行的环境中只修改名称或启动网址并保存
- **THEN** 管理界面立即显示新值，当前外部进程继续运行，下一次启动使用新网址

### Requirement: 运行中环境的停机配置字段保持锁定

系统 MUST 在环境运行或处于启动、停止、连接切换、配置保存等过渡状态时，将连接方式、授权测试站点来源和备注显示为不可编辑。名称和启动网址 MUST 在这些状态下继续可编辑。用户点击锁定字段时，系统 MUST 提示先停止环境；环境停止或新建环境时，受保护字段 MUST 可编辑。

#### Scenario: 编辑运行中的环境
- **WHEN** 用户打开运行中环境的编辑表单
- **THEN** 连接方式、授权测试站点来源和备注不可编辑，名称和启动网址仍可编辑

#### Scenario: 点击锁定字段
- **WHEN** 用户点击运行中环境的任一锁定字段
- **THEN** 系统提示用户先停止环境再修改该项

#### Scenario: 状态进入或离开过渡阶段
- **WHEN** 环境启动、停止、切换连接或保存配置
- **THEN** 三项受保护字段在过渡期间保持锁定，并在环境停止后恢复可编辑

#### Scenario: 运行中只保存名称或启动网址
- **WHEN** 用户在锁定其余字段的情况下修改并保存运行中环境的名称或启动网址
- **THEN** 保存成功，连接方式、授权测试站点来源和备注保持原值
