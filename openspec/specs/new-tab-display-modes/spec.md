# New Tab Display Modes Specification

## Purpose

规定新标签页的默认沉浸背景布局、简约布局切换、搜索框可见性、刷新行为、快捷入口和背景效果控制，并明确这些状态在多个新标签页之间的同步与重启后的持久化行为。

## Requirements

### Requirement: 默认沉浸背景布局

新标签页 MUST 默认使用 `immersive` 模式，模式状态 MUST 保存在全局浏览器设置中。该模式 MUST 渲染搜索框、快捷入口和右上角显示模式按钮；如果设置中存在合法背景媒体，媒体 MUST 覆盖整个新标签页。

#### Scenario: 默认打开沉浸布局

- **WHEN** 用户打开新标签页且没有保存显示模式
- **THEN** 页面使用沉浸背景布局并显示搜索框、快捷入口和右上角显示模式按钮

### Requirement: 显示模式切换

右上角显示模式按钮 MUST 提供“沉浸背景”和“简约指纹”两个可选择项。选择后 MUST 立即更新当前及其他已打开的新标签页，并在重启后保持选择结果。无效或缺失的模式值 MUST 回退到 `immersive`。

#### Scenario: 切换显示模式

- **WHEN** 用户在右上角菜单选择另一种显示模式
- **THEN** 当前及其他已打开的新标签页立即使用所选布局，重启后仍保持该选择

### Requirement: 两种模式的搜索交互

两种模式 MUST 渲染同一个搜索表单。搜索输入非空时 MUST 隐藏快捷入口，清空后 MUST 恢复；提交搜索词、直接导航和最近搜索建议 MUST 继续遵循新标签搜索历史规范。

#### Scenario: 搜索框保持可用

- **WHEN** 用户在任一显示模式输入搜索词或网址
- **THEN** 快捷入口按输入状态隐藏或恢复，提交行为继续遵循新标签搜索历史规范

### Requirement: 新标签页刷新

刷新按钮、刷新快捷键和 Agent 的 `reload` 控制作用于新标签页时 MUST 重新渲染当前显示模式、背景、搜索建议和快捷入口，不得导航到空白页。普通网页标签 MUST 继续使用网页视图的刷新接口。

#### Scenario: 刷新新标签页

- **WHEN** 用户刷新当前新标签页
- **THEN** 页面仍为新标签页并重新渲染当前模式、背景、搜索建议和快捷入口

### Requirement: 频次快捷入口

新标签页自动识别的快捷入口 MUST 继续按当前浏览器环境的有效访问次数和最近访问时间排序；手动配置入口 MUST 保留，且同一主机名 MUST 只显示一次。每个 HTTP(S) 快捷入口 MUST 优先显示该网站通过当前浏览器环境获取的 favicon；图标请求失败或图标无效时 MUST 显示配置中的文字图标回退。

#### Scenario: 合并自动和手动入口

- **WHEN** 自动识别入口与手动入口同时存在
- **THEN** 系统按访问排序显示自动入口，并对重复主机只保留手动入口

#### Scenario: 快捷入口显示网站图标

- **WHEN** 新标签页渲染一个 HTTP(S) 快捷入口且网站提供可读取的 favicon
- **THEN** 入口显示该网站 favicon，并继续打开原配置地址

#### Scenario: 网站图标加载失败

- **WHEN** 快捷入口的 favicon 请求失败或返回的内容不是图片
- **THEN** 入口显示配置中的文字图标，布局和打开行为保持可用

### Requirement: 直接调整沉浸背景

新标签页右上角的显示模式菜单 MUST 提供背景不透明度和模糊度滑块。不透明度 MUST 限定在 0–100%，模糊度 MUST 限定在 0–40px。调整时 MUST 立即预览，完成调整后 MUST 保存到全局浏览器设置，并同步到所有已打开的新标签页和重启后的新标签页。两个值 MUST 独立于管理页的主题背景透明度和玻璃模糊度。

#### Scenario: 调整当前背景

- **WHEN** 用户在沉浸背景模式拖动右上角菜单中的任一滑块
- **THEN** 当前背景立即更新，滑块旁显示当前数值，搜索框和常用网站保持可用

#### Scenario: 保存并同步

- **WHEN** 用户完成滑块调整
- **THEN** 当前及其他已打开的新标签页使用保存后的值，重新打开浏览器环境后该值保持不变

#### Scenario: 非法或旧设置

- **WHEN** 持久化设置缺少新字段，或字段值不在允许范围内
- **THEN** 缺失值沿用此前主题显示值，非法数值被限制到允许范围内，不影响新标签页加载

## Verification

1. 新建标签页默认包含搜索框、快捷入口和模式按钮。
2. 两种模式均可切换并跨重启保留。
3. 新标签页刷新后仍是新标签页且内容重新读取。
4. 搜索时入口隐藏，清空后恢复；频次排序和手动去重保持；可读取的网站显示 favicon，失败时显示文字回退。
5. 右上角菜单可调节沉浸背景不透明度和模糊度，调整后实时生效并跨重启保留。
