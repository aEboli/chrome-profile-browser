# smart-new-tab-sites Specification

## Purpose
根据每个浏览器环境在本应用内的近期访问频次，自动更新新标签页常用网站入口，同时保留用户手动维护入口的方式。

## Requirements

### Requirement: 按环境识别常用网站

系统 MUST 仅根据当前浏览器环境在本应用内成功提交的顶层 HTTP(S) 导航记录常用网站。每个主机名在当前识别记录中至少访问两次，且最近一次访问发生在 90 天内，才可进入自动识别列表；连续 90 天没有访问的记录 MUST 过期。自动列表最多显示六个网站，并按访问次数、最近访问时间排序。

#### Scenario: 常访网站显示在新标签页

- **WHEN** 当前环境已成功访问同一网站主机名至少两次，且最近一次访问发生在 90 天内
- **THEN** 新标签页在手动配置网站之前显示该网站入口，入口按网站根地址打开

#### Scenario: 低频网站不进入自动列表

- **WHEN** 某网站主机名在最近 90 天内仅成功访问一次
- **THEN** 该网站不进入自动识别入口列表

#### Scenario: 不活跃记录过期后重新计数

- **WHEN** 某网站超过 90 天没有访问后再次打开
- **THEN** 旧记录已过期，本次访问从一次重新计数

#### Scenario: 只保留排名靠前的网站

- **WHEN** 当前环境中符合频次条件的网站超过六个
- **THEN** 新标签页只显示访问次数较高的网站；访问次数相同时最近访问的网站优先

### Requirement: 隔离并最小化访问记录

系统 MUST 将自动识别记录按浏览器环境隔离并保存在本机。记录 MUST 仅包含规范化网站根地址、访问次数和最近访问时间；系统 MUST NOT 从系统或外部浏览器导入历史，也 MUST NOT 保存页面路径、查询参数、片段、标题或凭据。非 HTTP(S)、含凭据、IP 地址和本地主机名不得进入记录。

#### Scenario: 不同环境使用独立识别结果

- **WHEN** 两个浏览器环境访问不同的网站
- **THEN** 每个环境的新标签页仅显示该环境自己的自动识别结果

#### Scenario: 重启后保留识别结果

- **WHEN** 浏览器环境重新启动，且记录仍在 90 天有效期内
- **THEN** 该环境继续显示此前符合频次条件的常用网站

#### Scenario: 不保存页面敏感部分

- **WHEN** 用户打开带路径、查询参数或片段的网页
- **THEN** 本地记录仅保存不含路径和查询信息的网站根地址、访问次数和最近访问时间

#### Scenario: 忽略不适合作为网站入口的地址

- **WHEN** 页面地址不是 HTTP(S)、包含账号凭据、是 IP 地址或是本地主机名
- **THEN** 系统不将该地址计入常用网站记录

### Requirement: 与手动常用网站共同显示

系统 MUST 在自动识别入口后继续显示现有手动配置的网站和添加入口。若自动识别网站与手动配置的网站主机名相同，系统 MUST 只显示手动配置的网站一次。手动添加、编辑和移除的现有行为 MUST 保持可用。

#### Scenario: 自动网站和手动网站同时存在

- **WHEN** 自动识别列表和手动设置中包含不同的网站
- **THEN** 新标签页先显示自动识别网站，再显示手动配置网站及添加入口

#### Scenario: 手动网站覆盖同主机自动入口

- **WHEN** 自动识别列表和手动设置中存在同一网站主机名
- **THEN** 新标签页只显示手动配置的网站入口

#### Scenario: 手动维护功能保持可用

- **WHEN** 用户从新标签页添加网站，或在浏览器设置中编辑、移除网站
- **THEN** 现有手动维护流程继续工作，变更只影响手动配置的网站

### Requirement: 清除浏览数据时移除自动识别记录

系统 MUST 在用户清除某浏览器环境的浏览数据时，同时删除该环境的自动识别访问记录；其他环境的记录和手动常用网站设置 MUST 保持不变。

#### Scenario: 清除当前环境记录

- **WHEN** 用户清除当前浏览器环境的浏览数据
- **THEN** 该环境不再显示此前自动识别的网站，后续访问可重新建立记录

#### Scenario: 不影响其他环境和手动入口

- **WHEN** 用户清除一个浏览器环境的浏览数据
- **THEN** 其他环境的自动识别列表和全局手动常用网站设置保持不变
