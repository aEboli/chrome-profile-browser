# Password Book

## Purpose

规定配置中心密码簿如何按网站 origin 组织并展开账号、如何在桌面和窄视口布局控件，以及浏览器网页登录保存时如何识别并更新已有账号密码。

## Requirements

### Requirement: 按网站折叠密码记录

配置中心密码簿 MUST 按规范化 HTTP(S) origin 分组显示当前环境的记录，且用户可展开或收起每个网站分组。origin 包含协议和端口。没有有效 HTTP(S) 地址的旧记录 MUST 按服务名分组。展开后 MUST 保留账号搜索、记录编辑、记录删除和默认掩码密码行为。收起的网站行 MUST 显示当前分组的第一条账号记录、对应的默认掩码密码和当前可见账号数量。密码值 MUST 仅在鼠标悬停或键盘聚焦时通过现有受控 IPC 读取，且在指针移开、焦点离开或页面重新渲染后立即清空并恢复掩码。

#### Scenario: 展开网站账号

- **WHEN** 用户点击一个已收起的网站行
- **THEN** 该网站的账号记录展开显示，多个账号时显示当前分组账号数量

#### Scenario: 同一网站记录分组

- **WHEN** 当前环境有多个登录地址属于同一 origin 的记录
- **THEN** 这些记录显示在同一网站分组中，其他 origin 和其他环境的记录不混入该组

#### Scenario: 保留无地址记录

- **WHEN** 当前环境包含没有有效 HTTP(S) 地址的旧记录
- **THEN** 该记录按服务名显示在可展开分组中

#### Scenario: 收起时预览首个账号

- **WHEN** 网站分组处于收起状态
- **THEN** 摘要行显示第一条账号、其掩码密码和当前可见账号数量

#### Scenario: 安全查看摘要密码

- **WHEN** 用户悬停或键盘聚焦收起摘要中的密码字段
- **THEN** 密码通过受控读取流程显示，并在鼠标移开或焦点离开后清空并恢复掩码

### Requirement: 响应式密码簿工具栏

密码簿的环境选择、搜索和添加记录操作 MUST 在足够宽的桌面视口中保持同一行，并在窄视口中适配可用宽度而不遮挡或溢出。

#### Scenario: 桌面工具栏单行

- **WHEN** 密码簿处于宽桌面视口
- **THEN** 环境选择、搜索和添加记录控件位于同一行

### Requirement: 重复网页登录更新密码

提交带账号和密码的登录表单后，浏览器壳 MUST 按当前环境、规范化 origin 和账号查询已有记录。记录已存在时 MUST 显示明确的更新密码提示，且用户确认后 MUST 更新已有记录而不新增重复记录；不存在时仍显示新增保存提示。提示 MUST 使用与浏览器壳一致的深色主题，取消或关闭时不写入记录。

#### Scenario: 保存新网页登录

- **WHEN** 当前环境下该 origin 尚无此账号记录，且用户确认保存
- **THEN** 密码簿新增一条记录并显示保存成功

#### Scenario: 更新已有网页登录

- **WHEN** 当前环境下该 origin 和账号已有记录，且用户确认更新
- **THEN** 提示显示“更新”，现有记录密码被替换，记录数量不增加并显示更新成功

#### Scenario: 取消更新

- **WHEN** 已有相同 origin 和账号的记录，用户取消更新
- **THEN** 原记录保持不变
