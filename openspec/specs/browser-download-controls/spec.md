# browser-download-controls Specification

## Purpose
明确浏览器环境内下载的暂停、继续、取消和完成文件操作，依据实际任务状态与恢复能力提供控制，同时在稳定的工具栏与面板中反馈进度，保持页面输入焦点和环境隔离。

## Requirements

### Requirement: 下载控制必须符合任务实际能力

下载面板 MUST 提供暂停、可用时继续和取消，并检查任务归属及当前状态。仅完成的任务 MUST 提供打开文件和所在目录；失败、取消和中断任务 MUST 显示准确状态，中断仅在 Electron 报告可恢复时提供继续。

#### Scenario: 暂停、继续与结束

- **WHEN** 用户暂停/继续一个下载或任务结束
- **THEN** 面板同步字节、状态和可用操作，失效或跨 profile 的控制被拒绝
- **AND** 不宣称服务器一定支持断点续传

### Requirement: 下载反馈必须保留页面焦点和稳定布局

下载按钮 MUST 在预留空间中显示活动数量、进度与完成反馈，面板操作 MUST 支持键盘和 Escape。下载事件 MUST NOT 抢走输入焦点、自动关闭 Agent 或导致相邻控件位移。

#### Scenario: 输入时收到下载状态

- **WHEN** 用户正在页面输入且下载开始、更新或完成
- **THEN** 当前页面和输入焦点保持，工具栏反馈更新且邻近控件位置不变
