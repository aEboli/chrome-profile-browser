# browser-bookmark-import Specification

## Purpose
在配置中心设置页将 Chrome、Edge 及用户手动选择的兼容 Chromium 书签来源一次性导入指定浏览器环境，保留文件夹层级并按完整 HTTP(S) URL 去重。

## Requirements

### Requirement: 设置页选择目标环境和多个来源
系统 MUST 在配置中心设置页提供书签导入入口，要求选择一个现有目标环境，并允许同时选择一个或多个浏览器来源。系统 MUST 支持 Chrome、Edge 的标准目录检测及手动选择兼容 Chromium JSON 或标准书签 HTML 文件，以覆盖 LinkFox、自定义目录和其他浏览器。

#### Scenario: 同时导入多个平台
- **WHEN** 用户选择目标环境并勾选 Chrome、Edge 及手动添加的 LinkFox 兼容来源后点击导入
- **THEN** 系统处理所有选中来源，并仅将有效新增收藏写入该目标环境

#### Scenario: 没有目标环境
- **WHEN** 没有可用环境或用户没有选择目标环境
- **THEN** 系统阻止导入并提示先创建或选择环境

### Requirement: 保留层级并按地址去重
系统 MUST 按 Chrome 收藏栏结构导入：书签栏根节点的内容 MUST 直接进入目标环境收藏栏根目录，其他书签、移动设备书签 MUST 作为根目录文件夹保留，MUST NOT 创建来源包装文件夹或额外的“书签栏”文件夹。同一父级下的同名文件夹 MUST 复用。系统 MUST 按规范化后的完整 HTTP(S) URL 排除来源内部、来源之间及目标已有收藏的重复链接，MUST 保留已有收藏的名称、位置和图标，MUST NOT 将同域名不同路径、查询或片段的链接合并。

#### Scenario: 书签栏直接进入收藏栏
- **WHEN** 用户导入 Chrome 书签，书签栏中有链接和“工作”文件夹，其他书签中有链接
- **THEN** 链接和“工作”文件夹直接显示在收藏栏根目录，其他书签中的链接位于根目录的“其他书签”文件夹

#### Scenario: 多来源同名文件夹
- **WHEN** Chrome 与 Edge 的书签栏都包含“工作”文件夹
- **THEN** 两个来源的新增链接进入同一个“工作”文件夹

#### Scenario: 书签 HTML 导出文件
- **WHEN** HTML 文件包含标记为书签栏的文件夹及书签栏之外的顶层链接
- **THEN** 书签栏内容进入根目录，书签栏之外的顶层链接进入“其他书签”文件夹

#### Scenario: 跨来源重复
- **WHEN** Chrome 和 Edge 中存在规范化后相同的网址且标题不同
- **THEN** 仅导入首次出现的链接，并将另一条计入重复数量

#### Scenario: 与已有收藏重复
- **WHEN** 来源链接与目标环境已有收藏的网址相同
- **THEN** 跳过来源链接，保留已有收藏全部属性

#### Scenario: 重复执行导入
- **WHEN** 用户再次导入内容未变化的来源
- **THEN** 新增链接数为零，并且不新增重复或空文件夹

### Requirement: 完整保存和明确报告
系统 MUST 显示新增、重复、无效链接数量和来源失败信息。系统 MUST 支持超过 200 项的合法收藏在导入和后续重载、编辑时完整保留。来源超出资源边界或损坏时 MUST 明确失败，MUST NOT 静默截断有效收藏。

#### Scenario: 大于旧容量的导入
- **WHEN** 合法来源包含 300 个唯一链接且没有超过资源边界
- **THEN** 所有 300 个链接成功保存，重启和编辑后仍完整存在

#### Scenario: 部分来源损坏
- **WHEN** 多个选中来源中有一个解析失败
- **THEN** 系统可导入其余有效来源并单独报告失败来源，失败来源不写入部分内容

#### Scenario: 非法或不支持的 URL
- **WHEN** 来源包含脚本、内部页面或非 HTTP(S) 地址
- **THEN** 系统跳过这些链接并报告数量，不执行或打开这些地址

### Requirement: 一次性读取和环境隔离
系统 MUST 仅在用户主动导入时读取来源，MUST NOT 建立文件监听、定时读取或自动同步，MUST NOT 修改来源文件。系统 MUST 只改变选定环境的收藏，并在保存后刷新已打开的目标内置浏览器。

#### Scenario: 来源后续变化
- **WHEN** 导入完成后来源浏览器新增或删除书签
- **THEN** 本应用的收藏保持不变，直到用户再次手动导入

#### Scenario: 目标环境正在运行
- **WHEN** 用户向已打开的内置浏览器环境导入书签
- **THEN** 该环境收藏栏显示导入结果，其他环境收藏不变，来源文件不变
