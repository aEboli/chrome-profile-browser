# 启动时确认出口 IP 变化

## 目的

在启动浏览器环境前核对当前公网出口 IP 与该环境上次成功启动时的 IP，减少连接意外变化造成的身份连续性问题。

## 行为

- 每个环境独立保存上次成功启动时探测到的公开出口 IP。
- 每次启动前复用当前环境的直连或节点检查探测出口 IP；首次启动、探测失败或缺少有效 IP 时不阻断原有启动流程。
- 当前 IP 与上次 IP 不同时暂停启动，提示两个 IP 并建议切换到上次出口 IP 对应的节点；用户确认后继续启动，取消则保持停止状态。
- 仅在浏览器成功启动后更新上次 IP；取消确认或启动失败不更新记录。
- 确认请求短时有效并绑定环境当前连接；确认期间连接发生变化时拒绝过期确认。

## 设计

- 复用主进程 `checkProfileConnection` 的出口探测，不新增外部服务或持久化字段以外的网络逻辑。
- 由主进程创建一次性确认令牌并校验 profile、节点、上次 IP 和有效期；renderer 只负责呈现二次确认。
- 探测不到出口 IP 时沿用既有启动流程，不将节点可达性检查失败升级为启动拦截。

## 验证

- 使用相同的公开 IP 启动环境，确认不显示确认框并启动成功。
- 使用不同的公开 IP 启动环境，确认提示同时显示当前 IP 和上次 IP；取消后环境保持停止且上次 IP 不变。
- 确认继续后环境启动成功，新的出口 IP 成为上次 IP；启动失败时保留旧 IP。
- 探测失败或返回非公开 IP 时确认不会阻断正常启动。
- 确认过期令牌、其他环境令牌和连接已变化的令牌无法启动环境。
- 运行相关 lifecycle 回归测试、JavaScript 语法检查和版本校验。
