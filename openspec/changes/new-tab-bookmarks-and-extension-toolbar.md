# 新标签页、收藏栏与插件快捷入口

## 目的

- 为内置浏览器提供类似常见 Chromium 浏览器的新标签页，统一承载搜索、常用网站和可选 Banner。
- 为 profile 增加收藏栏，并保持收藏数据与现有收藏按钮共用。
- 让带有 popup、side panel 或 options 页面入口的已启用插件可以从浏览器工具栏直接打开面板。

## 行为

- 内置浏览器启动时打开新标签页；点击加号、按 `Ctrl+T` 或关闭最后一个标签时进入新标签页。
- 网页请求新窗口或 `target=_blank` 时由浏览器壳创建新标签，标签之间互不影响。
- 新标签页默认使用 Google，可切换 Google、Bing、百度、DuckDuckGo 以及保存的自定义搜索 URL；常用网站支持在浏览器设置中编辑，也可从新标签页添加。
- Banner 支持 HTTPS/HTTP 地址、GIF、图片和视频 URL，也支持通过本地文件选择器读取为本地 data URL；媒体类型可以自动判断或手动指定。
- 收藏栏位于地址工具栏下方，默认只在新标签页显示；`Ctrl+Alt+D` 切换为所有页面显示，状态保存在应用设置中。收藏栏条目点击后在当前标签打开，收藏图标使用 `📿`。
- 已启用并具有面板入口的插件会显示在浏览器工具栏，点击对应图标直接打开插件面板；插件列表仍可用于启停和管理。
- 网页获得焦点时，主进程将 `Ctrl+Alt+D` 转发到浏览器壳，保证收藏栏快捷键不依赖地址栏焦点。

## 验证

- 启动内置浏览器，确认初始页显示搜索框、常用网站和收藏栏；点击加号及 `Ctrl+T` 后确认新标签页独立出现。
- 在设置中选择搜索引擎、编辑常用网站并保存，重新打开新标签页确认配置保留。
- 分别使用网络图片、GIF、本地图片和视频地址配置 Banner，确认新标签页能显示对应媒体。
- 在网页标签和新标签页按 `Ctrl+Alt+D`，确认收藏栏在“所有页面/仅新标签页”之间切换；点击收藏条目确认复用当前标签。
- 启用带 popup 或 side panel 的插件，确认工具栏出现插件图标并能打开面板。
- 运行 `npm test` 与 `npm run check`。
