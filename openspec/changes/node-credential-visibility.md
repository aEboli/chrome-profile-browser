# 节点编辑器凭据回显

## 目的

- 让订阅导入的 SOCKS5 用户名和密码在节点编辑器中可见，便于核对和修正认证配置。
- 保留订阅刷新和节点运行时对凭据的实际使用。

## 行为

- 主进程向本地管理页返回节点已有的用户名和密码，编辑表单直接回填明文值。
- 保存编辑时继续写回节点配置；订阅节点仍按现有规则保存，手动节点仍使用本地安全存储流程。
- 凭据不进入日志、错误诊断、订阅名称或节点列表之外的公共文案。
- hysteria2、tuic 等未实现核心适配的协议继续显示为不支持，不因凭据回显而改变协议能力。

## 验证

1. 导入带认证的 SOCKS5 订阅，打开节点编辑器，确认用户名和密码字段显示原值。
2. 不修改凭据保存节点，确认节点仍可使用原认证信息连接。
3. 检查应用日志和错误提示，不包含用户名、密码或订阅令牌。
