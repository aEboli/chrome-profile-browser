# 节点批量检查

## 目的

在节点管理页提供批量检查入口，减少逐行点击检查的操作成本。

## 行为

- 批量检查只处理当前节点分组和搜索筛选后的节点；明确标记为不支持的节点跳过。
- 检查任务在主进程中限制并发，单个节点失败不影响其他节点；每个节点仍沿用现有 TCP/代理握手检查和持久化结果。
- 批量运行期间按钮禁用，节点状态显示“检查中”，主进程的逐项状态推送仍实时刷新列表。
- 完成后显示可达、失败和跳过数量；已有单节点检查入口继续可用。

## 设计与验证

- 新增批量节点检查 IPC，复用去重的 `checkNodeConnection`，不重复实现检查协议。
- 节点页标题工具栏增加“批量检查”按钮，操作范围跟随当前筛选条件。
- 运行 `npm test`、`npm run check`，并通过界面检查成功、失败和筛选范围。
