# 订阅排序与深色面板统一

## 目的

- 让订阅源面板与节点工作台统一为紧凑的深色卡片风格。
- 支持订阅编辑、显式非负整数排序号和可视化排序操作。
- 确保订阅顺序在订阅源、节点分组和环境连接选择器中一致。

## 行为

- 每个订阅记录保存 `sortOrder`，只能是大于等于 0 的整数；数值越小越靠前。
- 订阅行最右侧提供编辑、上移、下移、刷新和删除操作；第一项不能上移，最后一项不能下移。
- 按住订阅行的空白区域可以拖拽到另一行，释放后保存新的顺序；按钮、输入框和交互控件不会启动拖拽。
- 编辑按钮打开与导入订阅相同的弹窗，回填订阅名称、地址和排序号；保存编辑只更新订阅记录，不重新导入节点。
- 未带排序号的旧订阅按原有顺序迁移为从 0 开始的排序号；任何排序变更后所有订阅消费者使用相同顺序。
- 订阅面板、节点分组、表格和常用面板使用统一的深色背景、边框、间距和蓝/青强调色，保留现有功能布局与可访问标签。

## 验证

- 导入两个订阅，编辑排序号后确认订阅面板、节点分组和环境连接选择器顺序一致。
- 点击上移/下移和拖拽订阅行后刷新应用，确认顺序和排序号持久化；输入负数、小数或文本时不能保存。
- 点击编辑确认弹窗回填正确，保存后节点数量、地址和订阅节点归属不变。
- 运行 `npm test` 和 `npm run check`。
