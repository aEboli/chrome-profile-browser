# 环境启动器入口

## 目的

- 应用启动后先显示类似 Chromium profile chooser 的环境启动器。
- 用户点击环境卡片即可直接启动对应浏览器环境。
- 启动器最后提供配置中心入口，继续使用现有工作台设置与环境管理能力。

## 行为

- 启动器以深色居中布局展示已保存的环境、添加环境卡片和配置中心卡片。
- 环境卡片复用现有 `profile:launch` IPC；正在运行的环境仍由现有启动/停止逻辑处理。
- 环境卡片分别提供进入按钮和连接选择器，不嵌套按钮；选择器直接显示当前节点或系统直连，下方显示最近检测状态与毫秒延时，未检测时明确显示“未测”。
- 启动器的连接选择器复用环境列表的分组、搜索、候选状态和 `profile:switch-node` IPC；测试当前连接仍复用已有检查入口。切换运行中的环境遵循现有重启流程。
- 添加环境卡片打开现有新建环境表单。
- 配置中心卡片进入现有设置页；设置页顶部提供返回启动器入口。
- 不改变 profile 数据结构、浏览器启动参数或代理核心生命周期。

## 验证

- 启动应用后默认可见启动器，保存的环境数量与卡片数量一致。
- 点击环境卡片会调用现有启动流程；点击配置中心进入设置页，点击启动器入口可返回。
- 启动器卡片可以展开并搜索节点，当前选择和最近延时可见；选择节点后状态更新，进入环境按钮仍独立可用。
- 运行 `npm run check` 与 `npm test`。
