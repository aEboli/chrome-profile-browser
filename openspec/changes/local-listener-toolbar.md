# 本地监听服务工具栏入口

## 目的

- 在浏览器工具栏增加本地服务入口，便于查看本机正在监听的 TCP 地址和端口，并直接打开网页服务。

## 行为

- 工具栏下载按钮旁增加“本地服务”图标入口；点击后打开服务列表面板。
- 主进程通过受 profile 窗口校验的 IPC 执行 Windows `netstat.exe`，只返回 TCP `LISTENING` 项，不保存扫描结果。
- 列表同时显示原始绑定地址和可直接访问的 HTTP/HTTPS 地址；IPv4/IPv6 通配绑定分别映射到 `127.0.0.1` 和 `::1`。
- 每次打开面板和手动刷新时重新读取监听项；点击地址后在当前标签导航。没有监听项或读取失败时显示对应状态。
- HTTP 为默认打开方式，用户可在面板中切换 HTTPS。

## 设计边界

- 不发送探测请求，不猜测监听服务的应用协议；用户负责选择 HTTP 或 HTTPS。
- 仅支持 Windows TCP 监听项；UDP 端口不属于此入口。
