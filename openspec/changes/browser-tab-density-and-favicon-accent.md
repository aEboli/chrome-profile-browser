# 标签密度与 Favicon 活动边框

## 目的

- 标签页数量增加时，让最近使用的标签保持可读标题，同时为较早且未点击的标签保留可识别的 favicon 入口。
- 让活动标签的边框颜色与当前页面 favicon 的主要颜色接近，增强标签与页面身份的关联。

## 行为

- 标签栏根据当前可用宽度动态计算可显示标题的标签数量；空间不足时，活动标签和最近点击的标签保留标题，其余未点击标签收缩为图标状态。
- 收缩标签仍可点击切换，悬停时显示关闭入口，原有关闭按钮、中键关闭、拖动排序和键盘切换行为保持可用。
- 页面 favicon 加载后尝试提取主要颜色；无法读取跨域 favicon 时使用稳定的主题回退色。活动标签的边框和高亮表面使用该颜色。
- 标签数量减少或窗口宽度变化后重新计算密度，必要时恢复标签标题。

## 可验证成功标准

1. 在标签栏空间不足时，活动标签和最近点击的标签显示标题，较早未点击标签显示 favicon；点击图标标签可以切换并使其恢复标题。
2. 活动标签的边框/高亮颜色随 favicon 主要颜色变化；favicon 无法读取时仍有稳定的可见回退色。
3. 收缩标签的关闭按钮在悬停时可用，拖动排序、Escape 取消拖动和中键关闭不受影响。
4. 窗口缩放或关闭标签后，标签密度会重新计算并恢复可用空间。
