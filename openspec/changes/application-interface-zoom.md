# 应用界面缩放

## 目的

为配置中心提供窗口级界面缩放，并为内置浏览器壳提供只作用于网页区域的快速缩放；浏览器壳的标签栏、地址栏和工具栏保持原尺寸。

## 行为

- 按住左 Ctrl 并向上滚动鼠标滚轮时，配置中心界面或当前浏览器网页 guest 放大 10%；向下滚动时缩小 10%。浏览器壳的标签栏、地址栏和工具栏不随 guest 缩放，右 Ctrl 不触发该操作。
- 左 Ctrl+0 将当前窗口对应的缩放恢复到 100%。
- 缩放比例限制在 50% 至 200%；达到边界后继续滚轮操作不再改变比例。
- 配置中心和每个内置浏览器窗口分别维护当前缩放比例，窗口打开时为 100%；关闭窗口后不保留该比例。
- 缩放操作后在窗口右上角显示当前百分比；后续缩放会更新百分比并重新计时，最后一次操作约 2.5 秒后提示自动消失。
- 配置中心缩放只改变配置中心窗口；浏览器壳缩放只改变当前 `<webview>` 的网页内容，切换或加载标签时沿用当前窗口比例；外部 Chromium 窗口不属于本功能范围。

## 设计

- 缩放比例保存在各自 renderer 窗口的临时状态中，不增加持久化设置或公共状态字段；guest 通过现有 webview 消息桥发送短期命令。
- 配置中心和浏览器壳在文档级处理滚轮与键盘输入；guest 使用受控 preload 在页面事件阶段拦截 Ctrl+滚轮/0，阻止 Chromium 默认处理，并仅把左 Ctrl 命令转发到壳窗口。浏览器壳 renderer 将比例应用到当前 `<webview>`，不调用宿主壳窗口的缩放接口。
- 配置中心使用宿主窗口的固定定位轻提示；浏览器壳把比例提示注入当前网页 guest 的右上角，并以 `role="status"` 提供辅助技术可读状态；计时器在每次操作后重置。

## 验证

- 在配置中心按左 Ctrl+滚轮，确认向上每档增加 10%、向下每档减少 10%；在浏览器壳工具栏或网页区域重复操作，确认只改变当前网页 guest 的内容比例，顶部壳区域尺寸不变。
- 左 Ctrl+0 在两种窗口中都恢复到 100%；右 Ctrl+滚轮和右 Ctrl+0 不改变应用或网页比例。
- 连续多次缩放时提示显示最新比例，并从最后一次操作起约 2.5 秒后自动消失。
- 在 50% 和 200% 边界继续滚动时比例不越界；关闭并重开窗口后比例为 100%。
- 对变更涉及的 renderer 脚本执行 JavaScript 语法检查，并运行相关 UI 回归测试。
