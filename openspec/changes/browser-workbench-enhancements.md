# 浏览器工作台与订阅持久化增强

## 目的

- 调整浏览器壳工具栏的操作顺序，使导航和地址输入位于左侧，环境连接信息位于右侧。
- 为浏览器环境提供本地书签和地址栏快速建议。
- 让订阅源及其节点在重启后可继续刷新，并支持节点编辑和详情查看。
- 在设置页同时提供代理核心和可选 Chromium 浏览器内核的更新入口。

## 行为

- 浏览器工具栏从左到右显示后退、前进、刷新、地址栏和打开按钮；环境名称、国家和 IP 在右侧固定显示。
- 地址栏聚焦或输入时显示书签、最近访问、匹配的地址和搜索快捷项；可用键盘或鼠标选择，收藏按钮可新增或移除当前 HTTP(S) 地址。
- 地址栏失去焦点或点击其他区域后收起建议列表；编辑 HTTP(S) 地址时暂时隐藏协议前缀，提交仍保留原协议，鼠标按住向左拖到文本起点时显示协议并允许选择完整地址。
- 书签按 profile 保存，浏览器关闭后仍可读取；书签地址只接受 HTTP(S) URL。
- 节点表为每个节点提供详情和编辑入口，双击节点行打开详情并可继续编辑。编辑订阅节点只更新允许的展示/连接字段，保留协议、核心配置和订阅归属；凭据不在渲染器中回显。
- 订阅 URL 和由订阅导入的节点配置以本地明文保存，以便重启后直接刷新；旧的加密 URL 在成功读取时迁移为明文。手动节点仍沿用现有敏感字段确认和安全存储策略。
- 设置页可下载官方 Chrome for Testing 稳定版并切换为外部 Chromium；Xray-core 和 sing-box 更新入口继续可用。内置 Electron Chromium 随应用版本更新，不在运行中热替换。

## 验证

- 检查浏览器壳 DOM/CSS 顺序、收藏和地址建议交互，确认重启后书签仍存在。
- 复核地址栏失焦和网页区域点击会收起建议列表；聚焦后确认 `http://`/`https://` 被隐藏、全选只覆盖可见主机文本，向左拖动到起点后协议出现且全选覆盖完整地址。
- 导入带 URL 的订阅，关闭并重新启动应用后刷新订阅，确认节点和订阅状态仍在；编辑节点后确认协议/核心/订阅归属不变。
- 在设置页分别触发浏览器内核、Xray 和 sing-box 更新入口，确认路径和版本状态写入设置。
- 运行 `npm test` 与 `npm run check`。
