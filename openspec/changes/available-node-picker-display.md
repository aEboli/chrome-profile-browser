# 可用节点分组与环境选择器展示

## 目的

让节点工作台的“全部”和手动分组、环境连接选择器只暴露最近检查可用的节点，同时保留订阅源分组中的全部订阅节点，并让选择器按订阅源分组切换。

## 行为

- “全部”和手动分组隐藏状态为 `error`、`failed`、`unreachable`、`invalid` 或 `aborted` 的节点；订阅源分组保留订阅返回的全部节点，包括这些不可用节点和不支持节点，便于查看订阅的完整节点集合；未检查和检查中的受支持节点仍显示。
- 环境编辑表单和环境连接下拉只允许选择最近检查成功（`ok`、`ready`、`available`、`healthy` 或 `reachable`）的节点。编辑环境时，当前已选但不可用的节点保留为现有值，避免保存时静默改成直连。
- 连接下拉保留系统直连，并按订阅源、手动节点和直连提供独立分组；同一时间只显示当前分组的节点，可切换分组后继续选择。
- 节点候选每行显示 `国家·IP·来源·属性`；来源和属性去掉末尾的 `IP`，例如 `日本·1.1.1.1·原生·住宅`。
- 节点候选同时显示最近一次连通性状态和延时，并提供闪电图标重新检查该节点或系统直连；检查失败后节点按不可用规则从候选中移除。
- 节点名称、协议和服务器地址作为候选的无障碍名称与悬浮提示保留，不改变节点 ID、订阅归属或连接切换 IPC。

## 设计

- 渲染层按使用场景复用状态集合：节点页“全部”和手动分组隐藏明确失败节点，订阅源分组保留全部订阅节点，环境表单和连接选择器仍只提供成功节点。
- 连接选择器在现有弹层内增加分组标签，候选数据仍来自主进程公开节点状态，不新增持久化字段。

## 验证

- 使用成功、失败、未检查、检查中和不支持节点的状态数据确认“全部”和手动分组隐藏明确失败节点，订阅源分组保留失败和不支持节点；环境候选只包含成功节点。
- 打开环境连接选择器，确认直连和各订阅源可独立切换，当前分组之外的节点不出现在列表中。
- 确认候选行按四段 IPPure 摘要显示，并移除来源/属性末尾的 `IP`；状态与延时显示在同一行，点击闪电图标会重新检查而不触发节点选择。
- 确认重测失败的节点立即从选择器候选中消失，成功重测后重新出现。
- 运行渲染脚本 JavaScript 语法检查。
