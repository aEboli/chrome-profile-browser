# 主题系统与自定义背景

## 目标

将管理页和浏览器环境窗口统一为参考图中的深色蓝色玻璃层次，并让用户在设置页配置颜色、玻璃模糊、圆角和自定义背景图片。

## 行为

- 默认主题使用钢蓝、暗蓝、孔雀蓝和银白组成的深色工作台配色。
- 设置页提供主题预设、语义颜色、背景图透明度、玻璃模糊和圆角配置。
- 颜色和背景图片实时预览，点击保存后写入本地状态文件，跨重启保留。
- 背景图片只接受图片类型，限制为 5 MB；主进程再次限制为受支持的 base64 `data:image/*` 且不超过 8 MB。
- 清除背景或恢复参考主题不会影响环境、节点和浏览器引擎配置。
- 主题变量同步到浏览器环境窗口的工具栏与助手面板。

## 验证

- `npm run check`
- `npm test`
- 手动打开“设置 > 主题配置”，切换预设、修改颜色、上传图片并保存；重新启动应用确认主题仍然存在。
