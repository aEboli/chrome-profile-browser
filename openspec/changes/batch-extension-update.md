# 插件批量更新

## 目的

- 在插件管理标题旁提供一个入口，批量执行现有的插件更新操作。

## 行为

- 操作范围是全部已安装插件，不受当前搜索筛选影响；空列表时按钮不可用。
- 用户确认一次后，按列表顺序更新插件：有官方在线来源时检查并应用官方更新，无在线来源时重新读取并加载本地目录代码。
- 每个插件更新失败时继续处理其余插件；完成后显示已更新、无可用更新和失败数量，并提供失败名称或运行时警告。
- 批量更新期间禁用插件行内的检查、更新、卸载和激活范围控件，避免并发修改。

## 设计

- renderer 顺序复用现有 `extension:update` IPC，不增加主进程接口或改变单个插件更新规则。
- 更新前只确认一次；逐项捕获错误，最后刷新状态并汇总结果。

## 验证

- 批量更新覆盖在线插件与本地插件，顺序执行，并对无更新和单项错误分别计数。
- 用户取消确认时不调用更新接口。
- 批量运行时禁用重复批量操作与插件行内操作；结束后恢复控件并刷新插件状态。
- 空插件列表时批量更新按钮不可用。
