# 品牌图标与自动简介

## 目的

- 将工作台侧栏和客户端窗口统一为简约指纹品牌视觉。
- 将可见产品名称统一为“简约指纹”。
- 使用同一份包含星、月、日元素的 SVG 资源，避免不同入口的图标不一致。
- 根据应用描述自动生成侧栏简介，并限制为 30 字以内。

## 行为

- 侧栏品牌标记和两个 HTML 页面的 favicon 直接引用 `src/assets/brand-icon.svg`；原生窗口使用由同一 SVG 生成的 Windows ICO 或跨平台 PNG，避免 Electron 原生图像接口丢失 SVG。
- 管理页、浏览器环境窗口和原生客户端标题均显示“简约指纹”。
- SVG 以指纹弧线为主体，并包含星星、月亮和太阳几何元素；不依赖字体或 Unicode 图形。
- 主进程从包元数据生成品牌简介，将 `Chromium profile`、代理工作台等术语压缩为中文后按 Unicode 字符截断至最多 30 字，再通过状态下发给渲染层。
- 包元数据缺失时使用本地隔离浏览器环境与连接节点管理作为后备简介。
- 原生图标资源只作为 SVG 的平台兼容派生物，不另行设计视觉样式。

## 验证

- 品牌单元测试校验简介长度、术语压缩和 SVG 资源内容。
- 运行 `npm test` 与 `npm run check`。
- 启动应用后人工确认侧栏品牌标记、管理页 favicon 和新建浏览器窗口标题栏使用同一图标。
