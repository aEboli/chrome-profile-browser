# 浏览器标签、连接位置与敏感字段保留

## 目的

- 在浏览器环境窗口最上方提供可新增、切换和关闭的多标签栏，视觉位置接近 Chrome 标签栏。
- 在连接信息区域显示可用的国家和 IP 信息。
- 将浏览器工具栏中的操作改为图标按钮，并隐藏原生菜单栏文字。
- 识别新导入节点中的账号、密码或核心密钥时，先询问是否长期保留。

## 行为

- 标签在同一 profile 的持久化 session 中运行；每个标签独立保留页面历史、地址和标题。Windows/Linux 浏览器壳使用 Electron 标题栏叠加，让标签行延伸到原生标题栏区域；原生窗口控制仍由系统提供，标签行空白区域可拖动窗口。
- 标签栏支持新建、切换、关闭，至少保留一个标签；常用 Ctrl+T、Ctrl+W、Ctrl+Tab 和 Ctrl+L 快捷键继续可用。
- 可用鼠标拖动标签调整同一窗口内顺序；被拖标签跟随指针，相邻标签平滑让位，松开后顺序立即应用；Escape、指针取消或窗口失焦会取消拖动并恢复原顺序。正常单击仍用于切换标签，关闭按钮和中键关闭行为保持可用。
- 国家优先使用出口探测结果，其次使用节点数据或从节点名称中的常见国家代码/旗帜推断；IP 优先使用节点最近探测到的公网出口地址，缺失时显示服务器地址并标记为待解析。
- 浏览器导航和扩展入口使用 SVG 图标，按钮保留无障碍名称和悬停提示；Electron 原生 File/Edit/View/Window 菜单不显示。
- 订阅或手动节点首次带有敏感字段时显示确认框。选择“长期保留”才会将字段写入本地状态并沿用现有 `safeStorage` 保护；选择不保留时仍可导入节点，但不保存这些字段。
- 国家代码识别只接受明确的代码边界（例如 `JP-1` 显示为“日本”），未知的显式国家文本保留为截断后的展示值；域名回退显示为“域名（待解析）”。
- 新建标签按钮紧邻最后一个标签，后面固定放置浏览器设置齿轮；新标签的地址栏保持空白，输入普通文字时按设置中的搜索引擎 URL（默认 Google 的 `%s` 模板）查询，明确的 HTTP(S) 地址和域名仍直接打开。
- 浏览器齿轮面板保存搜索引擎模板；Agent 协议、接口地址、模型和 Token 迁移到 Agent 对话页右上角设置。Token 不在公共状态或渲染器状态中返回；首次保存新 Token 时必须确认是否长期保留，确认后使用 `safeStorage` 保护，拒绝则不写入状态文件。
- 节点检查成功后，应用通过当前节点请求 IPPure 的公开出口接口，并在服务不可用时回退到 ip111.cn；探测结果持久化国家代码/名称，失败不阻断节点检查，私有或回环地址不发送查询。

## 可验证成功标准

1. 运行一个环境后可以新增、切换和关闭多个标签，每个标签地址和历史互不覆盖。
2. 工具栏连接区域能显示国家和 IP（无数据时有明确回退文案），节点检查更新 IP 后可同步到运行中的窗口。
3. 浏览器窗口不显示原生菜单文字，导航/打开/扩展/状态入口仍可通过图标和无障碍标签操作。
4. 导入或保存含敏感字段的新节点时出现保留确认；确认保留后重启应用仍能使用认证字段，拒绝后状态文件不含该字段。
5. 新建标签后的地址栏为空；提交非地址文字会生成 Google（或设置模板）搜索 URL，`+` 后的齿轮可读写 Agent 与搜索设置。
6. 已有公开 IP 的节点最终能显示查询到的国家；相同 IP 的并发查询只发送一次，私有 IP 保持明确的未解析状态。
7. `npm test`、`npm run check` 通过。
8. 将任一标签拖到其他标签之前或之后，松开后可见顺序与目标位置一致；点击标签仍能切换，关闭按钮及中键关闭仍有效；Escape、指针取消或窗口失焦后标签顺序不变。
