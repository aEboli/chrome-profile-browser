# 浏览器右键菜单、媒体播放与下载管理

## 目标

让内置 Chromium 页面遵循 Chrome 常见的链接、媒体和编辑上下文菜单行为，并把下载任务纳入当前 profile 的下载管理。

## 行为

- 网页右键显示与 Chrome 常用项一致的中文菜单：页面导航、链接新标签、保存/复制链接、选中文本搜索、编辑操作、图片操作和媒体下载；图片菜单提供在新标签页打开、另存为、复制图片、复制图片地址和创建图片二维码。
- 普通链接在当前标签导航；右键明确选择新标签时进入当前 profile 的新标签栏；带真实 URL 的 `target=_blank`、Ctrl/中键和网站新标签请求进入当前 profile 的新标签栏，OAuth 空白预创建、命名或带窗口特征的脚本请求在当前 profile 的独立弹窗中打开。
- webview 开启受控弹窗能力；独立弹窗沿用当前 profile 的 session、代理认证和导航限制，不创建脱离 profile 的原生窗口。
- Chromium 原生 video/audio 播放能力保持可用；视频和音频上下文菜单提供直接下载，下载任务写入 profile 独立目录。
- 工具栏提供下载管理入口，显示进行中与已完成任务，可取消进行中的下载、打开文件或所在目录，并清除已完成记录。
- Agent 入口位于地址栏外侧并始终可用，使用路径绘制的 SVG `AI` 标识，不再使用机器人图标；地址栏收藏星标固定在输入框右侧，与 Agent 入口不重叠。

## 验证

1. 在页面链接上左键、Ctrl/中键和 `target=_blank`，分别确认当前标签导航、后台新标签和前台新标签。
2. 由页面调用 `window.open` 打开 OAuth 或其他授权页面；确认它在当前 profile 的独立弹窗中打开，回调后原页面仍可继续，并且关闭环境时弹窗一起关闭。
3. 在普通页面、链接、图片和 video 元素上右键；确认图片菜单包含打开、另存为、复制图片、复制图片地址和图片二维码，复制到剪贴板的图像及二维码内容对应当前图片。
4. 打开带 controls 的视频，确认 Chromium 播放控件可操作；右键选择下载视频后，下载管理显示进度并可打开文件。
5. 检查 Agent 按钮位于地址输入框外侧且可用，收藏星标固定在地址栏内侧；AI 图标只包含 SVG 路径，没有机器人 symbol。
