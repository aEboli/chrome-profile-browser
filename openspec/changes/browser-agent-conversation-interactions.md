# Agent 对话模型与队列交互

## 目的

- 让浏览器网页助手在对话面板内直接切换已配置接口返回的模型。
- 让进行中的 Agent 操作可停止，并支持消息与快捷动作排队执行。

## 行为

- 点击当前模型会通过浏览器窗口的主进程接口拉取模型列表；列表只返回模型标识和展示名，不返回 Token。选择模型后立即保存当前环境的 Agent 模型设置。
- Agent 空闲时发送按钮显示发送图标；运行中显示动态进度动画，鼠标移入后显示停止图标，点击会停止当前模型轮次。
- 运行中可使用排队发送和立即发送图标按钮。排队消息追加到任务队列；立即发送消息插入队首并请求当前模型轮次停止。所有任务仍按顺序执行，不并发修改同一段对话历史。
- 运行中点击观察页面、读取页面、收集链接、收集表格和滚动快捷动作时，动作进入同一队列，当前操作完成后执行。

## 安全边界

- 模型列表请求继续在主进程执行，渲染进程只提交当前表单中的临时连接字段，Token 不进入公共设置或日志。
- 页面动作仍复用既有固定动作模板与串行执行层，不开放任意脚本执行。

## 可验证成功标准

1. 模型按钮可展开列表，列表失败时保留手动模型值并显示可读错误；选择列表项后当前环境设置更新。
2. Agent 运行中发送按钮具有动画、悬停停止和可点击停止行为。
3. 运行中排队和立即发送都能进入任务队列，立即发送优先于普通排队消息。
4. 运行中快捷动作可点击且不会被禁用，按队列顺序执行。
5. `npm run check` 与 `npm test` 通过。
