# 插件商店搜索与详情预览

## 目的

- 在插件管理页并列接入官方 Chrome Web Store 与 CRX Soso 的 Chrome 扩展搜索，让用户可以在应用内查看搜索结果和详情。
- 复用现有插件安装、CRX 身份校验、Manifest 校验、profile 激活和运行时同步流程。

## 行为

- 插件管理页可以打开商店发现面板，在官方 Chrome Web Store 与 CRX Soso 之间切换搜索，并显示图标、名称、简介、分类、评分和用户规模（来源可用时提供）。
- 点击搜索结果后，主进程读取对应来源的公开详情元数据；官方来源显示名称、简介、版本和 Manifest 版本，CRX Soso 还显示评分、用户规模和最低内核版本。
- 安装请求只传递受校验的 Chrome 扩展 ID；主进程通过 CRX Soso 的加密下载接口获取受控 HTTPS CDN 地址，再沿用现有 CRX/Manifest/扩展身份校验。
- 安装记录保留来源详情页地址和来源标记；CRX Soso 详情页同时保留官方 Chrome Web Store 地址供用户核对。
- 目前只支持可加载到 Chromium 的 Chrome CRX。Firefox XPI、Microsoft Store 应用和其他非 Chrome 条目不进入直接安装路径。
- 搜索或详情接口失败时，面板显示明确错误，不能写入插件状态；安装失败清理临时文件并恢复旧版本。

## 验收标准

1. 插件管理页可以打开商店发现面板，在官方 Chrome Web Store 与 CRX Soso 之间切换，输入关键词后显示结果卡片。
2. 结果卡片可以打开对应来源的详情预览，详情包含可用的名称、简介、版本或 Manifest 信息，并显示 Chromium 安装边界。
3. 主进程只接受合法 Chrome 扩展 ID，下载地址只接受 CRX Soso 允许的 HTTPS CDN 主机，下载包必须通过现有扩展身份和 Manifest 校验。
4. 搜索、详情、安装任一步失败都不会写入半成品插件记录，安装临时文件会被清理。
5. 现有本地导入、官方 Chrome Web Store 直装入口和 CRX Soso 安装入口继续可用。
