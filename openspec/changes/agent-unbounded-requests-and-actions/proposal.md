# 移除 Agent 请求与网页动作固定上限

## 目的

移除应用为 Agent/JEV 网络请求和网页动作输入设置的固定时间、字节、字符串、数值、批次及动作路径数量上限，让用户配置的上下文预算、模型能力和实际页面成为工作边界。

## 范围

- Agent 与 JEV 网络请求不再由应用定时终止或按固定字节数拒绝。
- 模型列表与连通性检查、流式/非流式模型请求和 JEV 请求都能由发起窗口取消；窗口销毁时取消其请求。
- 网页动作不再限制输入文本、选择器、坐标数值、滚动量、等待时长、点击次数、拖拽点数、按键数或单批动作数。
- 保留工具类型白名单、输入类型与有限数值检查、页面 viewport 坐标校验、当前 profile 隔离、文件选择授权和串行动作执行。
- 不改模型服务商、操作系统或 Chromium 自身的资源、上下文与 API 限制。
