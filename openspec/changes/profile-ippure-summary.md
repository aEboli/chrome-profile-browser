# 环境列表 IPPure 四值摘要

## 目的

在环境列表中把当前连接的出口信息收敛为四项可扫描的值，并直接使用 IPPure 的出口探测结果，减少节点连接细节对环境识别的干扰。

## 行为

- 节点或直连检查成功后保留 IPPure 返回的国家、公开出口 IP、IP 来源和 IP 属性。
- IP 来源按 IPPure 的 `isBroadcast` 显示“原生IP”或“广播IP”；IP 属性按 `isResidential` 显示“住宅IP”或“机房IP”，并兼容 IPPure ASN 类型字段。
- 环境列表的 IP 信息单元固定为 2×2：左上国家、右上 IP 地址、左下 IP 来源、右下 IP 属性；未查询的单项显示明确回退值。
- 点击该 2×2 单元会打开原有连接选择弹层，支持按节点、地址或订阅搜索并完成切换；单元本身不显示节点名称、协议、服务器地址、连通性状态和延时，启动器与环境编辑表单继续保留连接切换入口。
- IPPure 不可用时继续沿用现有 ip111.cn 回退探测；回退结果缺少来源或属性时不覆盖上一次有效值。
- 启动、定时刷新和批量检查最多同时加载 3 个节点；检查中或检查失败时保留上一次有效的四项值。

## 设计

- 在出口探测解析层将有限的 IPPure 字段转换为可持久化的 `ipSource` 与 `ipProperty`，不保存外部响应原文。
- 节点状态和直连状态分别保存四项结果，渲染层按当前环境连接读取，不重复发起网络请求。
- 所有自动和批量节点检查复用有界批处理，避免一次性发起全部 IPPure 出口探测。

## 验证

- 用包含 `isBroadcast` 与 `isResidential` 的 IPPure JSON 确认四项字段映射正确，并确认私有 IP 不被接受。
- 检查环境列表 DOM/CSS 只输出四个 IP 信息项，且 2×2 位置稳定；无查询结果时显示回退值。
- 检查启动、定时刷新和批量检查最多有 3 个节点处于加载状态，已有四项值在加载期间仍可见。
- 运行 JavaScript 语法检查并人工复核环境列表布局。
