# 关闭环境窗口时停止运行

## 目的

- 让用户关闭浏览器环境窗口后，环境的运行时资源与管理页状态保持一致。

## 行为

- 用户关闭某个浏览器环境窗口时，先执行与“停止环境”按钮相同的清理流程，再销毁窗口。
- 清理流程包括页面 guest、插件会话、Electron profile 会话以及该环境使用的外部 Chromium 和 Xray/sing-box 核心进程。
- 外部 Chromium 进程自行退出时，如果该环境仍有代理核心运行，也执行同一停止兜底。
- 窗口最小化或被隐藏不会触发停止；环境仍按现有后台运行策略继续工作。
- 应用整体退出继续使用主进程的统一回收流程；窗口异常销毁时由 `closed` 事件补偿清理仍存活的运行时。

## 可验证成功标准

1. 启动一个使用普通节点或核心托管节点的环境，关闭其浏览器窗口后，管理页状态显示“已停止”。
2. 关闭窗口后，该环境对应的核心进程和临时运行时不再保留；再次启动环境可以正常创建新的窗口和核心实例。
3. 最小化或隐藏环境窗口不会停止环境。
4. 外部 Chromium 退出后，核心托管环境不会留下孤立的核心进程。
5. `npm test` 和 `npm run check` 通过。
