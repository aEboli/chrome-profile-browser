# 本地密码簿

## 目的

- 在配置中心增加密码簿，集中记录服务、账号和密码。
- 密码簿按浏览器环境隔离，每条记录只属于一个环境。
- 让用户可以搜索和维护记录，并快速查看某个密码。

## 行为

- 密码簿支持新增、编辑、删除和搜索记录；每条记录包含服务名称、账号、密码，以及可选登录地址和备注。
- 密码簿页面提供环境选择器；新增记录固定归属当前环境，编辑时不能迁移环境。
- 主进程在保存、删除和读取密码时校验环境存在且记录归属匹配；删除浏览器环境时清理该环境的密码记录。
- 记录保存在应用本地状态文件中；密码优先由 Electron `safeStorage` 加密。
- 主进程公开的状态只包含非敏感记录字段；查看密码时按记录通过受控 IPC 返回，不随状态推送发送密码。
- 密码框默认为空值掩码；鼠标悬浮或键盘聚焦时取出并显示密码，指针移开或字段失焦后清空输入值并恢复掩码。
- 编辑时密码留空表示保留当前密码；新增记录必须提供密码。
- 配置中心列表按登录地址的 HTTP(S) origin 分组，点击站点行展开或收起账号；缺少有效登录地址的记录按服务名分组。工具栏控件在桌面宽度内保持同一行。

## 安全边界

- 密码不进入日志、错误信息或 renderer 初始状态。
- 公共状态中的每条密码记录都带有环境编号；没有有效环境归属的旧记录不向界面公开，且不能通过环境 IPC 读取。
- 系统密钥环不可用时沿用应用现有策略，降级为本地明文保存；应用数据目录和操作系统账户需要受到保护。
- 明文密码仅在用户悬浮或键盘聚焦单条密码字段期间短暂进入 renderer。

## 可验证成功标准

1. 可在选定环境下创建含服务名称、账号和密码的记录，并可选填写登录地址与备注。
2. 环境切换后只显示该环境的记录；不同环境间不能编辑、删除或读取对方的密码。
3. 可编辑非密码字段或替换密码；密码留空保存时旧密码仍可用，记录不能改属其他环境。
4. 删除记录后，列表与本地状态中均不存在该记录；删除环境时清理该环境的记录。
5. 搜索可按当前环境的服务、账号、地址和备注筛选记录。
6. 重启后记录仍存在；状态对象不含密码字段或明文。
7. 列表中的密码默认掩码；悬浮或键盘聚焦时显示真实值，移开或失焦后恢复掩码且输入框不保留明文。
