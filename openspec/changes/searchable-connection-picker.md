# 可搜索的环境连接选择器

## 目的

优化环境列表在节点和订阅数量较多时的连接切换体验，并在连接选择处直接呈现连通性信息。

## 行为

- 环境列表的“连接 / 连通性”列显示当前连接、检测状态和最近一次延时。
- 点击当前连接后打开分组选择器，候选节点按订阅源和手动节点分组；每个候选项显示协议、地址、连通性和延时。
- 选择器内支持按节点名称、地址、协议或订阅名称即时搜索，候选项过多时仅在弹层内部滚动，不推动页面整体滚动。
- 选择器弹层跟随触发项定位，在视口边缘自动调整展开方向并限制尺寸；滚动或窗口缩放后重新定位。
- 订阅源区域支持按名称、地址或状态搜索，并使用独立滚动区域；每个订阅同时显示其节点连通性汇总。
- 连接切换仍复用现有 `profile:switch-node` IPC，不改变节点检查和持久化规则。

## 验证

- 在 Electron 窗口中打开“环境”，确认当前直连/节点下方显示状态与 `ms` 延时。
- 在启动器和“环境”中打开选择器，确认弹层贴近对应 IP 信息块；滚动或调整窗口大小后位置同步更新，靠近视口边缘时仍完整显示。
- 展开连接选择器，输入节点名称或地址，确认列表即时筛选；清空搜索后可恢复完整分组列表。
- 在“连接节点”页输入订阅搜索词，确认订阅列表只显示匹配项且列表区域独立滚动。
- 运行 `npm test` 与 `npm run check`。
