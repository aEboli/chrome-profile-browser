# 环境当前连接测试与 WebRTC 防泄漏

## 目的

让环境列表可以直接检查该环境当前选中的连接，并修复代理环境中 WebRTC 或 QUIC 绕过代理暴露本机地址的问题。

## 行为

- 每个环境的连接栏提供一次“测试当前节点”操作；未选择节点的环境测试系统直连。
- 测试期间按钮显示处理中并禁止重复触发，完成后复用节点或直连的状态、阶段、错误和毫秒延时。
- Electron 环境在宿主 `WebContents` 和每个 `<webview>` guest 上设置 `disable_non_proxied_udp`；直连环境恢复默认 WebRTC 策略。
- 外部 Chromium 使用代理启动时附加等价的 WebRTC IP 处理策略并禁用 QUIC，避免建立绕过代理的 UDP 路径。
- 节点连通性检查表示代理端点/协议握手；核心托管节点会启动隔离核心并通过本地 SOCKS5 完成一次目标连接，不宣称目标站点内容可访问、出口 IP 固定或能绕过站点策略。

## 设计与验证

- 环境检查复用主进程已有的节点检查去重任务；直连复用已有直连检查任务。
- WebRTC 策略调用放在 `WebContents`，不调用不存在的 `Session` 方法；guest attach 后立即再次设置。
- 运行 `npm test`、`npm run check`，并在代理环境打开 WebRTC 检测页确认不再出现未走代理的公网候选地址。
