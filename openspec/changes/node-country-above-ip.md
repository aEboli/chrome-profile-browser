# IP 地址统一显示节点元信息

## 目的

在环境 IP 信息、节点表和节点选择项中统一显示节点元信息与 IP，便于快速识别节点出口位置。

## 行为

- 环境列表和启动器的 IP 信息、节点表（包括订阅源分组）及节点选择项均使用两行布局：“国家·来源·属性”与 IP 地址水平居中；元信息自然宽度小于 IP 地址时，只在国家/来源和来源/属性之间均匀扩展间距至与 IP 行同宽，元信息更宽时保持自然宽度；IP 地址始终使用正常字距。
- 国家复用 `country`、`countryName` 或 `countryCode`；来源复用 `ipSource` 或 `ipSourceLabel`；属性复用 `ipProperty` 或 `ipPropertyLabel`。
- 来源和属性值去掉末尾的“IP”，例如“原生IP”显示为“原生”，“住宅IP”显示为“住宅”。
- 国家、来源和属性文字保持自然宽度，两处组间距可扩展以对齐较宽的 IP 行；列表中的 IP 地址仍保留在元信息下方。
- 元信息行按来源与属性组合着色：广播来源优先为红色，其他机房属性为橙色，住宅属性为绿色；仅识别到原生来源时使用青蓝色，其他或未查询值保持次级文字颜色。
- 国家、来源或属性尚未查询到时，该项显示“未查询”；不根据节点地址或名称臆测信息。
- 系统直连候选有出口信息时采用相同布局；暂无出口信息时继续显示“系统直连”。
- 保留现有 IP 地址及其未解析回退文案；长元信息和 IP 在各自行内截断，并可通过悬浮提示查看完整值。
- 节点详情中的 IP 信息也采用元信息在上、IP 地址在下的布局。
- 不新增地理查询、持久化字段或 IPC。

## 设计

- 复用已有环境和节点状态字段，在节点表、订阅源分组、连接选择器、启动器和节点详情中统一渲染。
- 用内容自然宽度确定两行的共同居中宽度，仅扩展元信息的两处组间距；元信息使用语义颜色，IP 地址作为主要值保留；保持原有连接选择交互和筛选搜索。

## 验证

- 环境列表、启动器、节点表、各订阅源分组、节点选择器和节点详情均显示元信息在上、IP 在下。
- 确认“原生IP”“住宅IP”“机房IP”分别显示为“原生”“住宅”“机房”；未查询项显示“未查询”。
- 确认 IP 地址保持正常字距；元信息较短时仅扩展国家/来源、来源/属性之间的间距，元信息较长时保持自然宽度；两行居中且 IP 地址仍显示在元信息之后。
- 确认广播机房组合为红色、原生机房为橙色、原生住宅为绿色；未查询或无法识别的组合保留次级文字颜色。
- 国家查询结果经状态推送后更新环境摘要、节点表和选择项。
- 系统直连选择项有出口信息时显示两行，无信息时保留原有直连标签。
- 域名或尚未解析的节点仍显示现有 IP 回退文案。
- 检查窄窗口与长元信息，确认两行均在对应区域内截断且不覆盖相邻内容。
- `node --check src/renderer/renderer.js` 和 `node --test test/workbench-enhancements.test.js` 通过。
- 当前已运行的 Electron 窗口未重新载入 renderer，实际窄窗口布局需在应用重启后人工复核。
