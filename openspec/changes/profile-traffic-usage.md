# 按环境统计使用流量

## 目的

在环境列表和启动器中显示每个浏览器环境累计使用的上传、下载和总流量，并跨重启保留统计值。

## 行为

- 内置 Electron 环境按独立 profile session 统计 HTTP(S) 请求的上传体字节和响应 `Content-Length`，不把不同环境的请求合并。
- 流量计数在运行期间通过现有状态推送更新，停止环境或定时写回本地 profile；环境删除时随 profile 一起删除。
- 没有可观测字节数的响应不会伪造数据；外部 Chromium 仅显示此前已保存的累计值。

## 验证

- 纯函数测试覆盖计数归一化、请求体字节和响应头字节解析。
- 运行 `npm test`、`npm run check`，并人工确认环境列表的“使用流量”列和启动器卡片显示上下行及总量。
