# Agent 上下文阈值压缩与对话栏收敛

## 目的

- 取消 Agent 对话的固定消息条数限制，由已配置的上下文预算控制上下文裁剪和压缩。
- 当前任务上下文估算达到预算 90% 时可自动压缩早期对话；任务继续产生新消息后可以再次压缩，直到任务完成。每次压缩保留系统规则、当前任务和工具调用链。
- 对话栏底部只展示模型选择、思考等级、上下文使用量和必要的发送/停止控件，不展示 Agent 内部快捷动作和队列控制。

## 行为

- 主进程不因固定消息数量或请求/响应字节数拒绝请求；renderer 仍按上下文预算裁剪和压缩。
- renderer 按消息 JSON 长度估算 token；达到 `agentContextBudgetTokens * 0.9` 时压缩，压缩后只有产生新消息才允许下一次压缩。压缩时保留最近一组 assistant 工具调用及其连续 tool 结果。
- 模型选择控件显示 `模型 ID · 思考等级`，内部网页动作仍由模型工具调用驱动。
- 上下文使用量以圆环百分比显示并按使用比例变色；点击可主动压缩，低于 50% 时不执行并显示短暂淡出提示。

## 可验证成功标准

1. 超过 256 条对话消息不会触发固定消息数错误。
2. 上下文估算达到 90% 后可多次压缩；每次必须有新的对话内容，assistant 工具调用与紧随其后的 tool 结果保持成组。
3. 对话栏不显示快捷网页动作、排队发送和立即发送按钮；模型项显示模型 ID 与思考等级。
4. 上下文圆环显示动态百分比，低于 50% 点击不会压缩且提示会淡出。
5. 相关语法检查、单元测试和项目检查通过。
