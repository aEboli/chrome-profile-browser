# 浏览器环境的订阅自动选路与故障切换

## Why

环境连接目前保存为系统直连或一个固定节点。订阅虽然已按来源分组，用户仍需从订阅里的节点逐个挑选；固定节点故障时也要手动再选。希望把已有订阅作为一个连接选项，由应用在该订阅内选延迟较低的可用节点，并在当前线路故障时自动切到同一订阅的备用节点。

## What Changes

- 新增“订阅自动”连接模式，可在新建/编辑环境和环境连接选择器中选择一个已导入的订阅。
- 选择订阅时检查该订阅的受支持节点，按成功连通节点的延迟从低到高选择；延迟相同时沿用订阅节点顺序。
- 运行中的订阅自动环境检测到当前节点不可达时，重检该订阅的其他受支持节点，并切换到延迟最低的可用节点。
- 前端明确区分“系统直连”“指定节点”和“订阅自动”，订阅自动模式同时显示订阅名、当前实际节点、延迟及检查/故障状态。
- 保留现有直连和单节点选择流程。选择具体节点仍表示固定使用该节点，不自动改成订阅模式。

## Capabilities

### New Capabilities

- `profile-subscription-routing`：环境选择订阅作为节点池，自动择优、故障时在池内切换，并明确展示模式和当前线路。

### Modified Capabilities

无。

## Impact

- `src/main/main.js`：环境连接持久化与校验、订阅内线路选择、启动解析、健康检查后的故障切换及订阅刷新/删除时的连接引用维护。
- `src/renderer/renderer.js`、`src/renderer/index.html`、`src/renderer/styles.css`：环境配置和连接选择器中的订阅自动选项、模式标识、当前线路与状态。
- `src/main/store.js`：沿用现有 profile 持久化结构，兼容未包含新字段的既有环境。
- 新增路由选择逻辑测试，并扩展环境连接、订阅生命周期和界面回归测试。

## Explicit Boundaries

- 只允许选择本机已导入的订阅，不在环境连接设置中新增订阅 URL 输入或订阅导入流程。
- 自动择优和故障判断只依据现有节点连通性检查及其延迟；出口 IP 信誉信息不触发自动切换。
- 备用节点仅来自用户选定的订阅。没有可用节点时不得静默切到其他订阅、手动节点或系统直连；环境保留订阅自动模式并显示无可用线路。
- 自动故障切换通过每环境独立的本机转发器更新上游线路。内置 Electron 与外部 Chromium 保持进程、窗口、标签和当前页面文档不变；新连接走备用线路，已有连接不被主动断开。
- 订阅自动模式启动或切线时不弹出出口 IP 变化二次确认；启用该模式本身表示用户允许使用该订阅中择优的线路，前端仍需提示已切换及当前线路。直连和固定节点启动仍遵守现有出口 IP 变化确认。
- 当前节点恢复后不在同一运行周期内自动切回；下一次用户选择订阅或启动环境时重新择优。
