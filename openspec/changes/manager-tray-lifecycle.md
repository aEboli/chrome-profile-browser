# 配置中心托盘生命周期

## 目的

- 浏览器环境启动后让配置中心退到系统托盘，减少配置窗口对浏览器工作的干扰。
- 保留一个稳定的入口，用于恢复配置中心、查看运行中的浏览器和退出应用。

## 行为

- 应用启动时创建系统托盘图标，使用项目统一的原生品牌图标。
- 任一浏览器环境启动成功后，配置中心自动隐藏到托盘；再次启动已运行环境时也保持该行为。
- 配置中心的最小化和关闭操作只隐藏窗口，不停止浏览器环境或代理核心。
- 左键双击托盘图标显示并聚焦配置中心；右键菜单提供“展开配置中心”和“退出”。
- 鼠标悬停提示显示当前运行中的浏览器数量和名称；浏览器启动、停止或异常退出后同步更新。
- 当所有浏览器环境从运行状态变为已停止时，自动恢复并聚焦配置中心；应用启动时没有运行中的环境不触发弹窗。
- 托盘退出沿用应用现有的统一退出清理流程，回收外部 Chromium 和代理核心后再结束进程。

## 可验证成功标准

1. 启动一个环境后，配置中心不再显示为前台窗口，托盘图标仍可见。
2. 左键双击托盘图标能恢复并聚焦配置中心；右键菜单能展开配置中心或退出应用。
3. 托盘悬停提示能显示运行中的浏览器数量和名称，停止环境后提示同步减少。
4. 配置中心最小化、关闭或托盘隐藏不会停止正在运行的浏览器环境。
5. 点击托盘“退出”后，现有浏览器与代理核心清理流程仍然执行。
6. 最后一个运行中的浏览器停止后配置中心自动显示并聚焦；同一轮停止流程只触发一次，重新启动环境后可再次触发。
7. `npm test` 和 `npm run check` 通过。
