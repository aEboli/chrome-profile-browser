# 代理出口 IP 与国家探测

## 目的

- 修复浏览器连接区域显示本地代理监听地址或代理服务器地址的问题。
- 在节点检查成功后，通过当前节点探测实际公网出口 IP 和国家，并同步到节点表与运行中的浏览器壳。

## 行为

- HTTP、HTTPS、SOCKS5 和核心托管节点完成代理握手后，主进程通过该节点请求 `https://my.ippure.com/v1/info`。
- IPPure 不可用、被当前节点拦截或响应格式不支持时，回退请求 `https://ip111.cn/` 并解析页面中的公网 IP 和国家文本。
- 探测到的公网 IP 优先于节点服务器地址写入 `ipAddress`；有国家代码时持久化国家代码和本地化国家名称，并向浏览器壳推送最新值。
- 出口探测失败不把可达节点标记为失败；已有 IP/国家值保留，没有值时继续使用现有的未解析回退文案。
- 只接受公开 IP；私有、回环和保留地址不会写入出口信息，也不会发送地理查询。

## 设计与验证

- 复用现有 HTTP CONNECT、SOCKS5、TLS 和超时处理；出口探测使用独立连接，不影响原有节点握手结果。
- IPPure JSON 与 ip111.cn HTML 仅解析有限字段，不保存外部响应原文；成功结果通过现有状态持久化和浏览器连接广播路径更新，未命中出口结果时的地理回退查询按 IP 去重。
- 已验证 IPPure/ip111.cn 字段解析、直连 HTTPS 探测，以及本地 HTTP CONNECT 转发代理下的出口探测。
