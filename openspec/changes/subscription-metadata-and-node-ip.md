# 订阅额度识别与节点信息表增强

## 目的

- 从订阅响应头和常见的提示型伪节点中识别剩余流量、到期时间和下次重置时间。
- 将提示型伪节点从节点列表、分组和环境连接选择器中排除，并在订阅源区域展示识别结果。
- 将不支持节点保留在订阅记录用于统计，并在对应订阅源分组中保留查看，但从“全部”、手动分组和环境连接选择器中排除；订阅源显示总数、可用数和不支持数。
- 在节点表增加 IP 地址列，并修复长中文名称导致的列文字错位和溢出。

## 行为

- 优先读取 `subscription-userinfo` 及相关订阅响应头；缺失字段时回退识别节点名称中的中文/英文提示。
- 订阅的真实节点数不包含额度、到期、重置和公告提示行；刷新订阅时清理该订阅旧的提示行。
- 订阅卡片区分总节点数、可用节点数和不支持节点数，内部排序号只用于排序而不直接显示。
- 节点表继续保留地址（主机与端口），新增 IP 地址列；已有 IP 直接显示，域名节点显示原始主机名作为待解析地址。
- 节点名称、协议、地址、IP、核心、状态和操作列使用可收缩网格项与块级省略，长文本不得覆盖相邻列。

## 验证

- 纯函数测试覆盖响应头、提示行合并、字段优先级和伪节点过滤。
- 运行 `npm test`、`npm run check`，并人工检查订阅行统计、连接选择器和节点表列对齐。
