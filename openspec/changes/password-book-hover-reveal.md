# 密码簿悬停显示密码

## 目的

- 鼠标悬停密码框时可以快速查看已保存密码。
- 键盘聚焦仍可查看密码，指针移开且字段失焦后清除明文。

## 行为

- 密码簿列表中的密码默认以掩码显示。
- 指针悬停或密码框获得焦点时，通过受控 IPC 读取并显示密码；指针移开且字段失焦后立即清除并恢复掩码。
- 主进程继续校验环境和记录归属，密码不进入公共状态或日志。

## 验证

1. 指针悬停密码框时触发读取并显示明文，移开后恢复掩码。
2. 键盘聚焦密码框时显示密码，失焦且指针移开后输入值清空并恢复掩码。
3. 公共状态仍不包含密码字段，跨环境读取仍由主进程拒绝。
4. `node --test test/password-book-ui.test.js` 与 `node --check src/renderer/renderer.js` 通过。
