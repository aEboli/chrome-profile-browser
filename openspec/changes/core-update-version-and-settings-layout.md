# 核心更新版本反馈与设置页布局

## 目的

- 修复 sing-box 官方包解压总量超过限制后无法安装的问题。
- 更新核心后显示实际安装版本，并在更新可用时并列显示目标版本。
- 收紧设置页不必要的留白，恢复可见的主题预览。

## 行为

- 核心下载大小限制与解压总量限制分开；官方下载仍限制为 80 MiB，解压后最多允许 512 MiB。
- 已配置的自定义核心使用其安装记录中的版本信息，不再被随包内置核心的旧版本清单覆盖；手动切换核心路径时清除不再适用的版本与校验记录。
- 设置页显示当前版本和可更新版本；一键更新仍从官方 release 下载，校验 SHA-256 后安装，成功后显示安装版本。
- 设置页卡片按内容高度排列，主题预览保持紧凑且正确绘制。

## 验证

- `node --test test/core-updater.test.js`
- `node --test` 完整测试集。
- 对主进程、renderer 和更新器运行 `node --check`。
- 使用官方 sing-box release 完成下载、SHA-256 校验和临时目录安装。
