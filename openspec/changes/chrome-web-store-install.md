# Chrome Web Store 插件安装

## 目的

- 在插件管理页增加从 Chrome Web Store 安装公开扩展的入口。
- 接受 Chrome Web Store 详情页地址或 32 位扩展 ID，并复用现有插件解包、校验、profile 激活和运行时同步流程。

## 行为

- 管理页可以打开商店安装表单，输入 `chromewebstore.google.com` 或旧版 `chrome.google.com/webstore` 的扩展详情页地址，也可以直接输入 32 位扩展 ID。
- 主进程只接受 Chrome Web Store 官方 HTTPS 主机和合法扩展 ID，通过官方 CRX 更新端点下载包；下载限制重定向次数和文件大小。
- 下载完成后沿用现有 CRX/ZIP 和 Manifest V2/V3 校验；扩展名称、版本、路径和激活环境仍由现有插件记录维护。
- 插件发现面板同时提供官方 Chrome Web Store 搜索、详情预览和官方页面入口；CRX Soso 继续作为聚合发现来源。两种来源的安装都需要用户明确提交，不模拟商店页面按钮，不向商店上传插件内容。
- 安装失败不写入插件状态；安装成功后按现有逻辑同步运行中的 Electron 环境，并对外部 Chromium 提示重启要求。

## 验收标准

1. 插件管理页显示“从 Chrome Web Store 安装”入口，可提交合法商店详情页 URL 或合法扩展 ID；发现面板可切换官方 Chrome Web Store 与 CRX Soso。
2. 官方来源可搜索公开扩展、读取详情元数据并打开官方详情页；非 HTTPS、非官方商店主机、缺少合法扩展 ID或超限下载被主进程拒绝，并返回明确错误。
3. 有效商店包能经过 CRX/ZIP、manifest 和大小校验，按选定 profile 保存并加载；原有本地导入和在线更新行为不变。
4. 搜索、详情或安装失败时状态文件不增加半成品记录，已下载临时文件被清理。
5. 插件管理相关测试、语法检查和人工 DOM 检查通过。
