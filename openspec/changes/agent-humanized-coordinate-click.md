# 网页助手模拟人工坐标点击

## 目的

- 让网页助手的坐标点击更接近人工鼠标操作，减少页面只接受完整鼠标事件序列时的点击失败。
- 保留当前活动网页 CSS 像素坐标模型，让页面空白区域和没有可点击 DOM 元素的位置也能被点击。

## 行为

- `click` 动作先把当前页面视图聚焦，再沿短距离路径发送多次 `mouseMove`，到达目标后发送 `mouseDown`、短暂按压和 `mouseUp`。
- 双击和多次点击在每次点击之间保留短暂间隔；`mouse_move` 也使用相同的缓动移动路径。
- 坐标仍限制在当前活动页面可视区域，动作不会发送到浏览器壳层、其他标签或操作系统窗口。

## 可验证成功标准

1. 在当前网页中点击链接、按钮、画布以及空白区域时，页面能收到移动、按下和抬起事件。
2. 双击和右键点击仍保持对应的按钮与点击次数。
3. 切换标签后，旧标签不会继续收到点击事件，越界坐标仍被拒绝。
