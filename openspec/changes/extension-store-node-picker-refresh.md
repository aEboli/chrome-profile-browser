# 商店节点列表与线路刷新

## 目的

- 将插件商店的请求节点选择从原生下拉框改为可搜索的节点行列表。
- 切换商店请求节点后，使用新线路重新加载当前来源和关键词的结果。

## 行为

- 商店发现页和 Chrome Web Store 安装表单共享当前请求节点，并按订阅源、手动节点和系统直连分组显示。
- 节点列表支持按名称、地址、协议或订阅分组搜索；每行显示节点地址、连通状态、延时和重新检查操作。
- 发现页切换节点会清空旧结果并发起新的搜索；切换期间返回的旧请求不会覆盖新线路的结果。
- CRX Soso 保持系统直连默认；官方 Chrome Web Store 打开时由独立流程自动选择已检查可达节点，没有可达代理时不静默直连。

## 验收标准

1. 打开商店发现页，点击“商店请求节点”后能看到可滚动、可搜索的分组行列表。
2. 选择不同节点后，结果区显示加载状态并按新节点重新请求；快速连续切换时最终只保留最后一次线路的结果。
3. 安装表单和发现页显示相同的当前节点，节点状态和延时来自现有节点状态。
4. 原有商店搜索、详情和安装 IPC 参数仍传递所选节点 ID。
