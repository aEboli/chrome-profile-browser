# 浏览器页密码簿自动填充与保存提示

## 目的

- 让内置浏览器网页登录表单使用当前浏览器环境的密码簿。
- 登录提交后由用户明确选择是否记录账号和密码。
- 让已保存账号以接近 Chromium 密码候选框的悬浮弹窗展示。

## 行为

- HTTP/HTTPS 网页聚焦账号或密码输入框时，按当前网页 origin 查询当前浏览器环境的密码簿记录。
- 候选弹窗显示账号和掩码密码；点击候选后才通过受控 IPC 读取密码并填入当前登录表单。
- 网页提交包含账号和密码的登录表单后，由浏览器壳层在密码框附近显示保存提示；页面跳转后提示仍可操作。当前环境中已存在相同 origin 和账号时，提示更新密码，确认后更新现有记录；否则提示保存新记录。取消、点击其他位置或超时都会关闭。
- 候选弹窗随网页导航销毁；保存提示只为完成本次提交短暂保留，切换标签、关闭标签或超时后关闭。

## 安全边界

- guest preload 只发送当前页面提交的凭据，主进程按浏览器环境校验记录归属并使用现有密码加密策略保存。
- 候选查询只返回服务、账号、地址等公共字段；密码通过单独的环境校验 IPC 按需读取，不进入公共状态。
- 非 HTTP/HTTPS 页面不启用网页密码簿交互，拒绝把凭据写入其他环境。

## 可验证成功标准

1. 当前环境在网页登录框聚焦时能看到同 origin 的已保存账号候选，点击候选后账号和密码填入表单，弹窗随点击消失。
2. 提交包含账号和密码的登录表单后出现保存提示；新账号选择“保存”后新增记录，已存在账号选择“更新”后替换现有密码，选择“取消”不修改记录。
3. 候选弹窗点击页面其他位置或等待超时后关闭；保存提示可跨提交后的页面跳转保留，切换标签后不残留。
4. 不同浏览器环境之间不能查询、读取或保存对方的密码记录，公共状态仍不包含密码明文。
