# 浏览器快捷键与鼠标手势配置

## 目的

- 为浏览器环境补充可自定义的刷新和开发者工具快捷键。
- 支持按住指定鼠标键连续滑动触发导航或工具操作，默认右键“右滑 → 左滑”后退一页。
- 允许用户通过网页助手用自然语言配置这些控制项。

## 行为

- 默认快捷键为 `F5` 刷新、`F12` 切换开发者工具；浏览器设置中可改为带修饰键的组合，例如 `Ctrl+R` 或 `Ctrl+Shift+I`。
- 默认鼠标手势启用，使用右键，方向为右、左，动作是后退；按键、方向、动作、触发距离和启用状态均可保存。
- 手势每段至少移动 80 像素（可配置 16 至 400 像素）；未完成或不匹配的右键拖动仍保留普通右键菜单。
- 设置保存在本机应用状态中，并同步到已打开的浏览器环境；非法按键、方向、动作和距离由主进程拒绝。
- 网页助手提供受控的 `browser_configure_shortcuts` 工具。模型只能提交白名单字段，保存仍经过主进程设置校验。

## 验证

- 打开浏览器环境，按 `F5` 刷新当前页面，按 `F12` 打开或关闭开发者工具。
- 将快捷键保存为 `Ctrl+R` 与 `Ctrl+Shift+I`，确认新组合生效，旧组合不再触发。
- 使用右键按住完成右滑再左滑，确认当前页面后退；短距离、方向不匹配或普通右击不触发后退且仍能打开右键菜单。
- 在设置中修改鼠标按钮、方向、动作和距离，确认重启环境后配置保留。
- 在已配置模型的网页助手中输入自然语言控制要求，确认模型调用 `browser_configure_shortcuts` 后设置更新；非法参数显示可读错误。
- 运行 `npm test` 与 `npm run check`。
