# 插件商店代理线路

## 目的

- 允许用户为官方 Chrome Web Store 和 CRX Soso 的搜索、详情与安装请求单独选择节点，处理当前网络无法直连商店的问题。
- 商店代理线路不改变浏览器环境各自保存的连接节点。

## 行为

- 插件商店界面提供“商店请求节点”选择项；官方 Chrome Web Store 打开时默认从已检查可达的节点中随机选择一个，CRX Soso 保留系统直连和手动节点选择。
- 用户选择只作用于商店搜索、详情和安装请求，不写入 profile 或节点状态。
- 请求在主进程中使用节点；代理凭据不进入新增 IPC 返回值。HTTP/HTTPS、SOCKS5 节点直接转发；VMess、VLESS、Trojan、Shadowsocks 和 AnyTLS 节点通过短生命周期的 Xray 或 sing-box SOCKS 入站转发，请求结束后回收核心。
- 官方商店页面及 CRX Soso 页面、API、CRX 文件下载均沿选定线路请求；更新检查仍沿用现有更新策略。
- 无效、已删除或不支持的节点返回明确错误；代理失败不创建插件状态记录。

## 验收标准

1. 商店发现页和 Chrome Web Store 安装表单可选择系统直连或支持的节点。
2. 官方商店与 CRX Soso 搜索、详情和安装都使用所选节点，切换浏览器 profile 节点不会改变商店线路。
3. HTTP/HTTPS、SOCKS5 和核心托管节点请求均使用正确的代理传输；核心托管请求结束后临时进程被清理。
4. 节点凭据只由主进程读取并用于代理认证，不由新增 IPC 回传；失败时不写入半成品扩展记录。
5. 相关单元测试、语法检查和全量测试通过。
