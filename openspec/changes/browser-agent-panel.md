# 浏览器网页助手面板

> 虚拟鼠标、键盘和模型 bridge 的增量规范见 [`browser-agent-virtual-input.md`](browser-agent-virtual-input.md)。本变更保留面板和固定页面动作的基础约束。

## 目的

- 在 profile 浏览器工具栏提供一个机器人入口，打开类似 WorkBuddy 的右侧对话栏。
- 允许用户在当前网页上下文中读取页面信息、收集链接和表格，并执行少量明确的页面操作。

## 行为

- 机器人入口位于地址栏右侧、插件入口左侧；打开后右侧面板与网页并排显示，关闭后网页恢复全宽。
- 面板显示当前页面标题和地址，并保留本次打开期间的操作结果。
- 面板动作绑定当前活动标签；切换标签、导航或刷新后，页面上下文随活动标签同步。
- 快捷动作支持读取当前页面、收集链接、收集表格、滚动到顶部或底部。
- 对话输入支持以下明确指令：`打开 <URL>`、`点击选择器 <CSS 选择器>`、`填写选择器 <CSS 选择器>：<文本>`，以及上述快捷动作的中文表达。
- 页面操作只在当前页面视图执行：普通网页使用 `<webview>` 的顶层文档，内置 `about:newtab` 使用受控的新标签页区域；结果有数量和文本长度上限；不执行用户输入的任意 JavaScript，不读取本地文件，也不主动发起模型或第三方网络请求。
- 页面未就绪、导航失败或选择器无效时，在面板中显示可读错误，不阻塞浏览器导航。

## 安全边界

- 选择器和输入值作为数据传给固定动作模板，不能改变待执行脚本结构。
- 页面读取结果只展示在当前 profile 窗口；复制操作由用户显式触发。
- 本地动作执行层仍是唯一的页面操作边界；远程 Agent 接入后必须复用动作白名单和授权边界，不能直接执行任意脚本。

## 可验证成功标准

1. 启动 profile 浏览器后，工具栏可看到机器人按钮；点击按钮可打开或关闭右侧对话栏，网页区域随之伸缩。
2. 面板能显示当前页面标题和地址；导航或刷新后上下文同步。
3. 点击读取页面、收集链接、收集表格、滚动按钮，或输入对应指令后，面板显示成功结果或明确错误。
4. `点击选择器` 和 `填写选择器` 只作用于当前顶层页面；任意脚本字符串不会被直接执行。
5. `npm test`、`npm run check` 通过，且新增页面动作解析与静态界面检查覆盖核心路径。
