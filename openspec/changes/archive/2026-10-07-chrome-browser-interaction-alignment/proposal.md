## Why

当前浏览器已有标签、收藏夹、下载面板和历史页面，但操作与 Chrome 存在可确认的差异：`Ctrl+Shift+T` 被新建标签逻辑截获；后台打开链接仍激活标签；网页获得焦点后，多数浏览器快捷键无法到达外层窗口；查找缺少连续搜索和结果计数；历史仅保存在当前窗口内存中。导航和下载按钮也缺少与实际状态一致的反馈。

用户要求同时对齐常用操作、界面效果和缺失功能。本次以当前内置 Electron 浏览器壳的日常操作为范围，提供以下完整工作流。

## What Changes

### 常用操作

- 统一浏览器壳和网页焦点下的快捷键：新建、关闭、恢复、按序切换、按数字选择标签，聚焦地址栏，前进后退，普通/忽略缓存刷新，查找、历史和下载入口。
- `Ctrl+Shift+T` 恢复最近关闭网页；`Ctrl+1` 至 `Ctrl+8` 选择指定位置，`Ctrl+9` 选择最后一项；`Ctrl+PageUp/PageDown` 与 `Ctrl+Tab` 按可见顺序切换。
- 地址栏支持 `Alt+Enter` 前台新标签打开、Escape 恢复当前网址；Ctrl/中键打开链接保持原标签，Ctrl+Shift/Shift+中键前台打开。
- 标签右键菜单提供右侧新建、刷新、复制标签、固定/取消固定、网站静音/取消静音、关闭、关闭其他和关闭右侧；批量关闭保留固定标签。

### 界面效果

- 标签使用稳定的宽度与固定图标区；活动普通标签始终显示关闭按钮，其他标签在悬停或键盘聚焦时显示，固定标签只显示图标并排在左侧。
- 优化地址栏、按钮悬停、键盘焦点和菜单间距，保留现有主题与背景设置；新建按钮保持紧邻标签，窗口控制保留独立空间。
- 后退/前进按钮反映当前标签可用状态；页面加载时刷新按钮切换为停止，结束后恢复。加载指示、网站声音状态和下载进度使用预留区域。
- 菜单和浮层支持 Escape、外部点击关闭和键盘操作；动效服从系统减少动态效果设置。验收尺寸为 960、1280、1440 像素窗口宽度，并检查系统 150% 缩放。

### 功能补齐

- 顶部查找条支持即时查找、结果位置/总数、上一个/下一个、Enter/Shift+Enter、F3/Shift+F3 和 Escape；切换页面时结果与所属标签一致。
- 历史按 profile 本地保存最近 1000 个 HTTP(S) 页面地址、标题和访问时间，同地址更新最近访问；支持搜索、单条删除和确认清空，地址建议复用历史。清理浏览数据和删除 profile 同步清理历史。
- 下载面板提供暂停/继续、取消、完成后打开文件/目录；中断和不可恢复任务有准确状态，不向失败任务展示可打开文件按钮。下载按钮显示进行中数量、进度和完成反馈，保持输入焦点。

## Capabilities

### New Capabilities

- `chrome-browser-shell-interactions`: 跨网页焦点的快捷键、地址栏、标签菜单、导航状态和页面查找。
- `profile-browsing-history`: 按环境持久化浏览历史和安全清理。
- `browser-download-controls`: 下载暂停、继续、准确状态和工具栏反馈。

### Modified Capabilities

- `chrome-tab-switcher-and-motion`: 活动标签关闭入口、固定标签、声音状态、后台打开和快捷键恢复。

## Impact

- `src/main/main.js`、`browser-shell-preload.js`：受控命令桥、网页快捷键转发、历史保存和下载生命周期。
- `src/main/store.js` 及必要纯数据模块：历史规范化、旧数据兼容、快捷键解析；只增加实际共用的数据规则。
- `src/renderer/browser-shell.js`、`.html`、`.css`：标签、导航、查找条、历史和下载交互。
- 对应行为回归测试、README、项目总规范和上述增量规范。

## Scope Boundaries

- 作用于内置 Electron 浏览器。外部 Chromium 沿用自身交互；现有 profile、代理、Cookie、密码、Agent 和扩展配置继续沿用。
- 本次以一个 profile 对应一个浏览器窗口为基础。独立多窗口、无痕会话、账号云同步和完整 Chrome 内部页面兼容需要另行定义生命周期与数据边界。
- 已有可配置刷新/开发者工具快捷键优先；固定 Chrome 快捷键不会造成重复触发，中文输入法组合输入不被提交或打断。
- 不迁移或修改其他浏览器的数据目录，不接入 Google 账号同步。

## Validation

- 用行为测试验证准确修饰键、后台焦点、关闭/恢复/固定顺序、信息状态、历史隔离与重启持久化、下载暂停/继续和失效操作拒绝。
- 用隔离 Electron 窗口加载本地页面，分别在浏览器壳、网页、输入框中验证快捷键；验证查找结果和加载/停止，不调用用户的真实网页或修改真实 profile。
- 在上述窗口尺寸和缩放比例检查截图与控件边界，验证菜单、查找条和 Agent 同时打开时不遮挡必要操作，并验证减少动态效果。
- 通过 `npm test`、`npm run check`、`git diff --check` 和 OpenSpec 严格校验后归档。
