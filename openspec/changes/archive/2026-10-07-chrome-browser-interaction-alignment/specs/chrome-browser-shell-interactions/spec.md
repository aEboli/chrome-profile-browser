## ADDED Requirements

### Requirement: 浏览器快捷键必须覆盖壳与网页焦点

内置浏览器 MUST 在壳与网页焦点下执行相同的标签、地址、导航、查找、历史和下载命令，准确判断修饰键，保护输入法组合输入，且每次按键只执行一次。已有可配置刷新和开发者工具快捷键 MUST 优先。

#### Scenario: 使用恢复快捷键

- **WHEN** 用户在网页或壳内按 Ctrl+Shift+T
- **THEN** 最近关闭的网页标签被恢复，不能创建空白新标签

#### Scenario: 在网页中切换和定位标签

- **WHEN** 用户按 Ctrl+Tab、Ctrl+Shift+Tab、Ctrl+PageUp/PageDown 或 Ctrl+1 至 Ctrl+9
- **THEN** 按可见顺序循环或定位对应标签，Ctrl+9 定位最后一项
- **AND** Ctrl+L 聚焦并选中地址栏，Ctrl+H 和 Ctrl+J 打开历史和下载

### Requirement: 地址提交与后台打开必须保持正确焦点

地址栏 MUST 支持 Enter 在当前标签打开、Alt+Enter 在前台新标签打开和 Escape 恢复当前网址。Ctrl/中键后台打开 MUST 保留当前活动标签和输入焦点，带 Shift 的前台请求 MUST 激活新标签。标签创建接口 MUST 区分是否激活与是否聚焦地址栏。

#### Scenario: 后台打开链接

- **WHEN** 用户 Ctrl/中键点击网页链接或收藏链接
- **THEN** 新标签加入当前 profile，当前活动标签和焦点不变

#### Scenario: 地址栏新标签提交与取消

- **WHEN** 用户按 Alt+Enter 提交输入或已选择的建议
- **THEN** 地址或搜索在新标签打开，不修改原标签
- **AND** Escape 取消地址编辑，恢复原网址并关闭建议

### Requirement: 标签菜单必须支持常用批量操作

标签菜单 MUST 提供右侧新建、刷新、复制、固定/取消固定、网站静音/取消静音、关闭、关闭其他和关闭右侧。固定标签 MUST 排在普通标签之前；批量关闭 MUST 保留固定项。菜单 MUST 支持键盘导航、Escape 和外部点击关闭。

#### Scenario: 固定与批量关闭

- **WHEN** 用户固定一个标签，再在普通标签上关闭其他或右侧标签
- **THEN** 固定标签保留在左侧，目标与保留标签的顺序和活动状态正确

#### Scenario: 网站静音

- **WHEN** 用户在菜单切换网站静音
- **THEN** 当前 profile 窗口内同 hostname 标签同步静音状态，声音标识反映实际播放与静音

### Requirement: 导航工具栏必须准确反映页面状态

后退和前进按钮 MUST 与当前标签的导航能力同步；加载时刷新按钮 MUST 切换为停止，结束后恢复。普通刷新、忽略缓存刷新和停止 MUST 作用于当前标签。布局 MUST 为所有状态预留固定空间，并在验收窗口尺寸和缩放下保持必要操作可见。

#### Scenario: 导航、切换与停止

- **WHEN** 用户导航、切换标签或停止加载
- **THEN** 导航按钮、加载标识和刷新/停止按钮只显示当前页面状态，不沿用其他标签状态

### Requirement: 页面查找必须支持连续操作

Ctrl+F 与菜单 MUST 打开紧凑查找条，提供输入、当前匹配位置/总数、前后匹配和关闭。Enter/F3 MUST 查找下一项，Shift+Enter/Shift+F3 MUST 查找上一项，Escape MUST 关闭并清理查找状态。异步结果 MUST 验证所属标签和请求。

#### Scenario: 连续查找与切换页面

- **WHEN** 用户输入文字、前后切换匹配，或在查找过程中切换/导航标签
- **THEN** 显示正确结果位置和总数，旧页面结果不能更新新页面的查找条
- **AND** 关闭、导航或销毁时停止对应查找
