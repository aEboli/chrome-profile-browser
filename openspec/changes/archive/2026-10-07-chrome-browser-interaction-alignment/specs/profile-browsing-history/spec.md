## ADDED Requirements

### Requirement: 浏览历史必须按环境持久化

应用 MUST 为每个 profile 本地保存最近 1000 个已访问 HTTP(S) 页面，包含地址、标题和最近访问时间，同地址更新最近访问。历史 MUST 来自该环境主框架已提交的导航，剔除 URL 用户名密码，且不得记录新标签或其他壳页面。缺失历史字段 MUST 按空数组兼容。

#### Scenario: 环境重启与隔离

- **WHEN** 用户访问页面后停止并重新启动环境
- **THEN** 当前环境历史与地址建议仍可读取该记录，其他环境不能读取它
- **AND** 页面标题更新补充对应记录，而不是创建重复地址

### Requirement: 历史删除与清理必须完整

历史页面 MUST 支持按标题/地址搜索、删除单条记录和确认清空。接口 MUST 依据 sender 身份限定 profile。清理浏览数据和删除 profile MUST 同步删除该环境历史，不能删除其他环境的数据。

#### Scenario: 删除记录和清空

- **WHEN** 用户删除单条记录或确认清空历史
- **THEN** 页面、地址建议和持久化数据同步更新，取消清空不改变记录

#### Scenario: 清理环境浏览数据

- **WHEN** 用户清理一个环境的浏览数据或删除环境
- **THEN** 该环境历史被清除，其他环境历史保持不变
