验收使用现有 Electron 44.4.3、临时数据目录和本地 HTTP 服务，加载实际主进程函数、preload 与 renderer，不启动网络探测、升级监控、托盘，也不读取真实 profile。

已通过 15 项流程：后台保持当前标签、固定网页关闭后快捷键恢复、真实查找计数 1/3 与 2/3、原生标签菜单条目、网页焦点 Ctrl+L、Alt+Enter 新标签打开、前进/后退能力、历史持久化与环境隔离、历史搜索连续输入、更多菜单键盘导航与 Escape、网站静音、真实文件下载暂停/继续到完成、刷新切换停止加载、系统减少动态效果，以及历史单条删除、清空与浏览数据清理。

最终自动化检查：299/299 项测试通过，49 个 JavaScript 文件语法检查与版本一致性校验通过，OpenSpec 全量严格校验 19/19 与差异检查通过。

截图和边界检查覆盖 960、1280、1440 像素内容宽度与 150% 系统缩放，查找条和 Agent 同时显示。工具栏入口、窗口设置、新建标签与查找条均在视口内，页面为实际 HTML 内容，查找高亮与结果计数可见。

## 环境限制

- 当前 Playwright 的 Electron 自动接管及 CDP 接管在此 Electron 版本连接超时；改用隔离窗口内部 Chromium 接口、实际事件、截图和边界检查完成验收。
- Electron 44 在移除 webview 时打印 `WebViewElement.disconnectedCallback` / `Invalid guestInstanceId`，部分页面采色请求还打印 `UnknownVizError`。关闭/恢复和历史切换仍完成；没有把这些内部销毁报错计为无错误桌面验收。这项运行时限制需要后续 Electron 生命周期专项修复。
- 用户主动停止加载产生 Chromium `ERR_ABORTED (-3)`，页面停止与刷新按钮恢复已验证。
