# 主题化确认弹窗

## 目的

- 将配置中心和内置浏览器壳中分散的浏览器原生确认/输入窗口统一为应用内主题弹窗，避免深色界面中出现白色系统窗口。

## 行为

- 批量更新、单个插件更新、删除插件/节点/订阅/环境/密码记录、恢复 Agent 配置和出口 IP 变化确认都使用统一弹窗。
- Agent/JEV 密钥和节点凭据长期保留确认由发起保存操作的 renderer 窗口展示，并把用户选择返回主进程。
- 浏览器壳中添加常用网站和查找页面内容使用主题化输入弹窗；常用网站名称、地址和图标分步输入。
- 弹窗显示操作标题、主要说明和可选补充说明；删除类操作显示危险色图标与确认按钮。
- 确认、取消、右上角关闭、Escape 和点击遮罩分别产生明确结果；取消不会调用对应主进程操作。
- 确认弹窗默认聚焦确认按钮，键盘 Enter 可完成确认；文本输入弹窗默认聚焦输入框。
- 弹窗沿用配置中心主题变量、背景模糊、边框、圆角和按钮规范，在主题变化后保持一致。

## 设计

- renderer 通过 `requestConfirmation` 或 `requestShellInput` 返回 Promise，调用方等待用户结果后继续原有流程。
- 主进程通过受限的 request ID 和 IPC 响应通道，把密钥保留确认发给发起保存操作的 renderer；renderer 销毁或超时按不保留处理。
- 复用现有 modal backdrop 和 SVG 图标，不引入新的窗口或系统对话框。

## 验证

- 深色主题下确认弹窗与页面表面、文字和按钮颜色一致。
- 每个原确认场景的确认与取消结果保持不变，取消时不触发 API。
- Esc、关闭按钮和遮罩点击可以取消弹窗，确认按钮可以完成操作。
- 确认弹窗打开后键盘焦点位于确认按钮；输入弹窗仍聚焦文本框。
- 敏感凭据确认只响应发起操作的 renderer；renderer 关闭或超时时不保留未确认的密钥。
