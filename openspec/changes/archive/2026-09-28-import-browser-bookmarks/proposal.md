## Why

用户需要把 Chrome、Edge、LinkFox 等浏览器的收藏栏和其他书签一次性迁入本应用，并在同时导入多个来源时排除重复链接。

## What Changes

- 配置中心的设置页增加“导入浏览器书签”，选择一个目标环境，勾选一个或多个来源后导入。
- Chrome、Edge 检测标准用户数据目录中的配置文件，并显示可选来源；自定义安装位置、LinkFox 和其他浏览器支持手动选择 Chromium Bookmarks JSON 或浏览器导出的书签 HTML 文件。未经验证不声称支持 LinkFox 自动检测。
- 导入收藏栏、其他书签及嵌套文件夹，按来源和浏览器配置文件组织到目标环境的收藏栏中。
- 按规范化后的完整 HTTP(S) URL 在本批次及目标环境已有收藏中去重；保留已有收藏的名称、位置和图标。同网址不同标题视为重复，路径、查询参数或片段不同的地址保留。
- 重复导入不新增重复链接或空的来源包装文件夹；结果显示新增链接、重复链接、无效链接和各来源读取失败信息。
- 取消现有 200 项静默截断；读取文件与处理条目设置明确的资源边界，超限时明确拒绝该来源，不默默丢弃有效书签。
- 仅在用户点击导入时读取来源；不建立后台同步，不写入来源浏览器数据。可再次手动导入新增内容。

## Capabilities

### New Capabilities
- `browser-bookmark-import`: 设置页中的多来源一次性书签导入、去重、结果报告及环境隔离。

### Modified Capabilities
无。沿用现有收藏的 HTTP(S) 协议限制和按环境保存方式。

## Impact

- 新增书签导入模块，承担来源检测、JSON/HTML 解析及合并。
- 修改主进程、preload 和设置页，增加受控导入接口和界面；已打开的目标环境接收收藏更新通知。
- 调整收藏规范化的容量处理，避免导入后在后续编辑或读取时再次被截断。
- 增加导入、去重、异常来源、持久化及 IPC 校验测试。
- 目标为本应用内置浏览器的环境收藏，不直接修改外部 Chromium 的书签数据库。
