## Context

现有收藏使用 profile.bookmarks 扁平数组及 parentId 保存文件夹树。主进程负责 URL 校验和持久化，内置浏览器负责展示；配置中心已有独立设置页。目前 normalizeBookmarks 在 200 项时直接截断，不能沿用到批量导入。

## Decisions

1. 设置页选择单个目标环境，来源可多选；没有环境时提示先创建环境。保留现有环境间隔离语义。
2. Chrome、Edge 从官方文档或源码确认的标准目录检测配置文件；扫描仅限候选数据根目录及其配置文件目录，不递归扫描整个用户磁盘。LinkFox 默认目录未验证，先用文件选择器支持其兼容 JSON 或导出 HTML 文件。
3. 文件读取和解析在主进程完成。界面提交主进程分配的来源标识，手动来源经系统文件选择器选择。HTML 只提取标题、地址和文件夹结构，不执行脚本或加载远程资源。
4. 沿用现有 URL 规范化规则。目标环境已有链接优先；来源按界面顺序处理，首次出现的链接胜出。保留路径、查询和片段，不按域名合并。
5. 来源包装文件夹仅在有新增链接时创建；重用同来源包装文件夹，并保留有效新增链接的祖先层级，避免重复导入产生空文件夹。
6. 各来源先解析再合并。单个来源损坏或超限时报告失败，其他有效来源可继续；写入前重新读取目标环境最新收藏进行去重，防止异步读取期间覆盖用户新收藏。
7. 取消 200 项读取截断。初始资源边界拟为每文件 20 MiB、每来源 50,000 节点、层级 100；超限明确失败，目标环境总容量校验在提交前完成，不部分截断。
8. 保存后通知运行中的目标内置浏览器刷新收藏。通知仅传递本应用状态，不触发重新读取来源。

## Verification

使用临时目录及合成 JSON/HTML 测试多配置文件检测、中文标题、嵌套文件夹、跨来源重复、与已有收藏重复、二次导入、200 项以上数据重载、非法协议、格式损坏及资源边界。校验来源文件字节不变、其他环境不变；通过 UI 或可复核交互检查单选/多选、无目标环境和结果反馈。

## Limitations

仅导入有效 HTTP(S) 链接；内部浏览器页、脚本书签等明确计入跳过结果。LinkFox 专有或加密格式不宣称兼容；出现此类文件时提示从来源浏览器导出标准 HTML。
