## ADDED Requirements

### Requirement: 直接调整沉浸背景

新标签页右上角的显示模式菜单 MUST 提供背景不透明度和模糊度滑块。不透明度 MUST 限定在 0–100%，模糊度 MUST 限定在 0–40px。调整时 MUST 立即预览，完成调整后 MUST 保存到全局浏览器设置，并同步到所有已打开的新标签页和重启后的新标签页。两个值 MUST 独立于管理页的主题背景透明度和玻璃模糊度。

#### Scenario: 调整当前背景

- **WHEN** 用户在沉浸背景模式拖动右上角菜单中的任一滑块
- **THEN** 当前背景立即更新，滑块旁显示当前数值，搜索框和常用网站保持可用

#### Scenario: 保存并同步

- **WHEN** 用户完成滑块调整
- **THEN** 当前及其他已打开的新标签页使用保存后的值，重新打开浏览器环境后该值保持不变

#### Scenario: 非法或旧设置

- **WHEN** 持久化设置缺少新字段，或字段值不在允许范围内
- **THEN** 缺失值沿用此前主题显示值，非法数值被限制到允许范围内，不影响新标签页加载
