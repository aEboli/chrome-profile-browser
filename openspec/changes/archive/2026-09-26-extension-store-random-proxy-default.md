# 官方 Chrome Web Store 默认代理

## 目的

- 修复官方 Chrome Web Store 打开时默认走系统直连的问题。
- 默认线路必须使用已通过节点握手检查的代理节点，不改变 profile 的连接设置。

## 行为

- 打开官方 Chrome Web Store 发现页或安装表单时，主进程检查已配置且受支持的代理节点，并从可达结果中随机选择一个。
- 选择结果只作用于商店请求；用户仍可在节点选择器中改选其他节点或明确选择系统直连。
- 搜索、详情和安装请求沿自动选择或用户选择的线路发送；没有可达代理节点时显示明确错误，不静默回退到系统直连。

## 验收标准

1. 官方 Chrome Web Store 发现页切换打开后，节点选择器显示一个随机的可达代理节点并使用它加载结果。
2. 官方 Chrome Web Store 安装表单打开后，默认线路完成同样的随机可达节点选择。
3. 没有可达代理节点时，官方商店请求失败并提示原因；明确选择系统直连后仍可按用户意图直连。
4. 选择代理时不改变 profile 的节点、运行状态或其他商店来源的默认线路。
