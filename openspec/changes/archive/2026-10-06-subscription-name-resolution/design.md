# 设计

- `subscription-name` 作为纯数据模块负责候选名称清洗、来源判断、节点备注兜底和账号标识分配。
- 名称来源按手工名称、响应头/下载文件名、URL 名称提示、节点备注、URL 主机名、通用默认值排序；URL 解码后的不透明 token 在分隔符清洗前过滤，节点候选复用 `isSubscriptionInfoNode` 排除整条元数据提示行及其主机名。
- 订阅记录保存 `nameSource` 与 `accountTag`。刷新仅在 `nameSource` 不是 `custom` 时重新计算名称，避免覆盖用户改名。
- store 载入时先预留所有有效账号标识，再为缺少标识或标识重复的历史记录分配下一个未占用标识；主进程导入新订阅时沿用已有标识。
- renderer 将名称和标识组合为统一显示标签，重命名编辑只编辑名称本体，不把标识写回名称字段。
