# 设计

- 使用 `jevAutoJudgeEnabled` 作为持久化字段，默认值为 `true`，并加入 Agent 单环境覆盖白名单。
- 主进程根据有效配置生成 Agent 工具列表；关闭后过滤 `jev_decide`，JEV IPC 入口也拒绝调用。
- 浏览器壳根据同一有效配置跳过自动完成判断，并在没有启用 JEV 时按普通 Agent 结果结束网页任务。
- 配置页位于 JEV 连接字段前，保存和回填共用现有 Agent 配置流程。

## 决策

- 默认开启是为了升级时保留现有用户行为；用户可显式关闭，也可为单个环境单独覆盖。
- JEV 关闭时不保留手动的 `jev_decide` 模型工具入口，保证“关闭即不加入”。
