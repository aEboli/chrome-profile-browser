# 本地服务停止操作

## 目标

在浏览器壳的“本地服务”列表中，为每个已识别的本地前端服务提供停止入口，并在执行前要求用户二次确认。

## 行为

- 每条本地服务在项目名和地址右侧显示停止图标；图标提供“停止此服务”的标题和辅助技术标签。
- 点击停止图标打开应用内确认弹窗，显示项目名、访问地址和监听端口；确认按钮使用危险操作样式。
- 用户取消确认、关闭弹窗或确认请求失败时，不调用停止接口，服务继续运行。
- 用户确认后，主进程重新读取本机监听服务并校验 PID、端口、项目名以及服务识别结果；列表过期、PID 已复用或目标不再是已识别前端服务时拒绝停止并返回可读错误。
- 校验通过后，主进程使用 Windows `taskkill` 终止目标进程树；停止成功后刷新本地服务列表，失败时保留列表并显示错误。
- 停止接口只接受受限的数值 PID、端口和当前项目名输入，不接受任意命令行或可执行文件路径。

## 影响范围

- `src/main/local-listeners.js`：发现结果携带 PID，并增加重新发现、校验和停止进程树的主进程逻辑。
- `src/main/main.js`、`src/main/browser-shell-preload.js`：增加 profile-scoped 停止 IPC。
- `src/renderer/browser-shell.js`、`src/renderer/browser-shell.css`：增加停止图标、确认流程、刷新和错误反馈。
- `test/local-listeners.test.js`：同步发现结果 PID 和浏览器壳 IPC 静态断言。
