# 新标签页沉浸背景与显示模式切换

## 目标

让新标签页默认呈现参考图一的全屏背景布局，同时保留参考图二的简约布局作为可切换模式；恢复始终可见且可用的新标签搜索框，并让快捷入口继续按当前浏览器环境的访问频次自动排序。

## 行为

- 新标签页默认使用 `immersive` 模式：背景媒体覆盖整个标签页，搜索框位于内容区域上方，快捷入口显示在搜索框下方，右上角显示显示模式按钮。
- 显示模式按钮使用图标并提供可访问名称；点击后打开选项，可在“沉浸背景”和“简约指纹”之间切换。选择结果按浏览器设置持久化，并立即刷新所有已打开的新标签页。
- “简约指纹”模式使用深色无全屏背景的内容布局，保留搜索框、常用网站入口、添加入口和可选 Banner；搜索框在两种模式下均必须渲染。
- 常用网站入口按当前浏览器环境在应用内记录的有效顶层 HTTP(S) 访问次数和最近访问时间排序；手动入口仍保留，且同主机名只显示一次。
- 新标签页的刷新按钮、刷新快捷键和 Agent 的 `reload` 控制在新标签页上重新渲染当前模式、背景、搜索建议及常用入口，不导航到空白页；普通网页标签继续调用网页刷新。
- 搜索框输入非空内容时隐藏快捷入口，清空后恢复；提交搜索词和直接导航继续遵循现有搜索历史规则。

## 可验证成功标准

1. 新建标签页默认显示全屏背景、搜索框、快捷入口和右上角模式按钮；搜索框可以聚焦、输入并提交搜索。
2. 点击模式按钮后能选择两种显示模式；切换后当前及其他已打开的新标签页立即更新，重启后保留最后选择。
3. 在同一浏览器环境中多次成功访问网站后，新标签页入口按访问次数降序、最近访问时间降序排列；手动入口不丢失且不会重复同主机名。
4. 在新标签页点击刷新或按配置的刷新快捷键，页面仍保持新标签页模式并重新读取搜索建议和常用入口；普通网页标签仍正常刷新。
5. 新标签页输入非空搜索词时快捷入口隐藏，清空后恢复；网址导航不写入搜索历史。
