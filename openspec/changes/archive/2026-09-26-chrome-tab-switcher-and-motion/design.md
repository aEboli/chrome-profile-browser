## Context

浏览器壳在 renderer 中维护当前窗口的 `tabItems`，通过 `renderTabs()` 统一更新标签栏。标签视图可以在切换时保留，因此列表面板应读取壳内状态，并在已有标签事件后重新渲染。

## Goals / Non-Goals

**Goals:** 提供靠近 Chrome 的首部列表入口，快速搜索、切换和关闭标签，恢复近期误关的网页标签，并让活动、进入和排序状态清楚可辨。

**Non-Goals:** 跨窗口或重启保存最近关闭项；修改网页助手入口；改变标签导航、页面历史或拖动排序模型。

## Decisions

- 将列表按钮放在标签栏最前面，并以锚定在标签行下方的面板显示打开标签和最近关闭标签。按钮、面板和搜索框提供无障碍名称与状态。
- 标签栏关闭图标保留固定宽度，平时隐藏，在指针悬停或键盘聚焦该标签时显示，降低误关并保持标题布局稳定。
- 搜索对标题和网址执行不区分大小写的即时子串匹配。面板条目把切换与关闭做成不同按钮，关闭事件不会冒泡为切换操作。
- 最近关闭列表保存在当前 renderer 会话内，最多 20 项；新标签页不加入记录。恢复时用保存的网址创建标签，并恢复标题、favicon 和强调色。
- 复用现有的标签渲染和拖动排序流程。活动高亮表面以位置和宽度过渡；新增和重排使用短暂的 CSS 动画。
- 使用 `prefers-reduced-motion: reduce` 关闭标签栏的装饰性 transition 和 animation，不改变切换、关闭、拖动和恢复行为。
- `Ctrl+Shift+A` 打开或关闭列表面板；Escape、点击外部和选择标签关闭面板。网页助手继续使用独立工具栏入口。

## Risks / Trade-offs

- 最近关闭项只在当前窗口进程会话中存在，符合局部恢复的范围，也避免把网页历史额外持久化。
- 系统减少动态效果时，位置变化不再动画；标签的最终状态和可操作区域保持不变。
