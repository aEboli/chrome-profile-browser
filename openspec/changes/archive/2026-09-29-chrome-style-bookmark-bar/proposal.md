## Why

从 Chrome、Edge 导入书签后，全部内容被放进“Chrome · Default”这类来源包装文件夹，并多出一层“书签栏”文件夹，和原浏览器的收藏栏结构不一致。收藏栏文件夹点击后在同一个菜单中逐级替换内容，需要“返回上一级”，放不下的收藏只能隐藏滚动，与 Chrome 的使用习惯差异较大。

## What Changes

- 导入不再创建来源包装文件夹：书签栏根节点的内容直接进入收藏栏根目录，“其他书签”“移动设备书签”作为根目录文件夹保留；书签 HTML 中带 `PERSONAL_TOOLBAR_FOLDER` 的文件夹按书签栏处理，书签栏之外的顶层链接归入“其他书签”。
- 同一父级下同名文件夹复用（包括已有文件夹），多个来源的同名文件夹合并；仍按完整 URL 去重，重复导入不产生空文件夹。
- 收藏栏文件夹左键展开为下拉菜单，只显示内容；子文件夹悬停或点击时在右侧展开级联子菜单，支持方向键进出子菜单；菜单打开时悬停到收藏栏上的其他文件夹直接切换；再次点击同一文件夹收起。
- 文件夹菜单底部和文件夹右键菜单提供“全部在新标签页中打开（n）”；管理操作只保留在右键菜单中。
- 收藏栏放不下的条目收进末尾“»”菜单，不再横向滚动。
- 修复文件夹和默认收藏图标显示为实心黑色、加载中图标错位的样式问题。

## Capabilities

### Modified Capabilities
- `browser-bookmark-import`: 导入位置与 Chrome 收藏栏结构一致，不再使用来源包装文件夹。
- `bookmark-bar-management`: 文件夹级联展开、全部打开和溢出菜单。

## Impact

- `src/main/browser-bookmark-import.js`：解析和合并逻辑。
- `src/renderer/browser-shell.js`、`src/renderer/browser-shell.css`：收藏栏菜单与样式。
- 旧版本导入产生的来源包装文件夹不会自动迁移；删除该文件夹后重新导入即可得到新结构。
