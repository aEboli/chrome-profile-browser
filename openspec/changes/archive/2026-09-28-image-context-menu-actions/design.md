## Context

图片菜单由主进程根据当前 guest 的上下文菜单参数构建。参数包含图片地址和右键坐标；页面二维码窗口已经由主进程生成。

## Goals / Non-Goals

**Goals:**

- 让复制图片读取当前 guest 中右键位置的图片。
- 复用现有二维码窗口生成流程，同时标明二维码对应图片。

**Non-Goals:**

- 不改变页面、链接、文本、视频或音频菜单。
- 不增加 IPC、依赖或持久化数据。

## Decisions

- 使用 Electron `webContents.copyImageAt(x, y)` 从当前 guest 复制指针位置的图片。当前 Electron 44.4.3 类型声明包含该 API；直接使用它可避免重新下载图片及跨域读取问题。
- 将页面二维码生成函数扩展为通用资源二维码函数，并传入窗口标题。图片菜单编码 `srcURL`，页面菜单继续编码页面 URL；这样两类入口共用同一窗口和错误处理。

## Risks / Trade-offs

- 右键事件缺少有效坐标时，复制图片无法执行；复制函数会在调用 Electron API 前验证坐标。
- 图片地址过长时二维码库可能无法编码；继续使用现有二维码错误处理，不阻断浏览器操作。
