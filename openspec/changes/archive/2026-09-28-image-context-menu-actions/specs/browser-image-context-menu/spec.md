## Purpose

让用户能从浏览器图片右键菜单直接复制当前图片、复制其地址，或分享其地址二维码。

## ADDED Requirements

### Requirement: 图片右键菜单提供常用图片操作

图片上下文菜单 MUST 提供“在新标签页中打开图片”“图片另存为…”“复制图片”“复制图片地址”和“为此图片创建二维码”操作。

#### Scenario: 图片菜单显示完整操作
- **WHEN** 用户在网页图片上打开上下文菜单
- **THEN** 菜单显示打开、另存为、复制图片、复制图片地址和创建图片二维码这五项操作

### Requirement: 图片操作针对当前图片

图片上下文菜单中的复制图片操作 MUST 把当前右键位置对应的图像内容写入剪贴板；复制图片地址 MUST 复制当前图片地址；创建二维码 MUST 编码当前图片地址并显示对应二维码。

#### Scenario: 复制图片内容
- **WHEN** 用户在图片上选择“复制图片”
- **THEN** 剪贴板包含该图片的图像内容

#### Scenario: 复制图片地址
- **WHEN** 用户在图片上选择“复制图片地址”
- **THEN** 剪贴板包含该图片的地址

#### Scenario: 创建图片二维码
- **WHEN** 用户在图片上选择“为此图片创建二维码”
- **THEN** 应用显示编码该图片地址的二维码窗口
