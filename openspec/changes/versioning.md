# 版本号管理

## 目的

- 为每次代码更新提供可追踪的产品版本号，并在应用界面和请求标识中使用同一版本。
- 让大版本、小版本、小功能更新和普通更新的递增规则可执行、可校验。

## 规则

- 展示格式为 `大版本.小版本.更新号`，更新号固定三位：`1.0.000` 表示大版本，`0.1.000` 表示小版本。
- 小功能更新每次将更新号增加 `010`，例如 `0.0.230` → `0.0.240`；普通更新每次将更新号增加 `001`。
- 每次只递增一个层级；大版本或小版本递增时，下级版本号归零，例如 `0.6.116` → `0.7.000`。
- `package.json` 的 `appVersion` 保存三位补零的产品版本；标准 `version` 和锁文件使用 npm 兼容的无前导零值。

## 验收标准

1. 应用侧栏显示当前产品版本，主进程状态、插件更新请求和核心更新请求使用同一版本。
2. `npm run version:patch`、`npm run version:feature`、`npm run version:minor`、`npm run version:major` 按规则更新并同步包元数据。
3. `npm run version:check` 能发现 `package.json`、`package-lock.json` 和展示版本不一致。
