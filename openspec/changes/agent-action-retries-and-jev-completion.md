# 网页助手动作说明、自动重试与 JEV 完成判断

## 目的

- 让对话中的动作卡片说明实际执行的动作和关键参数，便于用户判断网页助手正在做什么。
- 遇到可恢复的工具执行失败、Agent/JEV 请求失败或超时时，按动态间隔自动重试，减少任务意外中断。
- 网页任务执行后使用已配置的 JEV 模型判断任务是否完成，并向用户展示每次判断的完成状态和置信度；未完成时继续让 Agent 处理。

## 行为

- 鼠标和虚拟输入动作卡片包含可读动作及关键参数。例如点击显示“点击页面坐标（420, 260）”，滚动显示方向和距离，键盘动作显示按键组合；敏感输入内容不直接放进动作标题。
- 首次调用失败后最多重试 5 次，重试间隔依次为 1、2、4、8、16 秒；用户停止任务或窗口关闭时取消后续重试。
- Agent 模型、JEV 判断、只读页面操作及能够确认尚未产生副作用的失败可自动重试。点击、提交、上传等动作若超时且无法确认是否已经生效，不盲目重复执行；先重新观察页面并交由 Agent/JEV 判断当前状态，再决定是否继续。
- 对包含网页操作的 Agent 任务，在每批动作结果返回后自动请求 JEV。判断状态包括用户目标、已执行动作及结果、当前页面观察和已知错误；问题要求 JEV 返回 `completed`（布尔值）、`confidence`（0 至 1 或 0 至 100）和简短 `reason`。
- 每次 JEV 判断都在对话中显示完成/未完成、置信度和理由。未提供有效置信度时显示“未返回”，不自行推算。
- JEV 判断未完成时，把判断结果交回 Agent 并继续循环；判断已完成时，要求 Agent 基于已有结果生成面向用户的总结，不再发起网页操作。达到用户配置的工具步数上限、用户停止或 JEV 在重试后仍不可用时，明确说明任务尚未得到完成确认。
- 普通闲聊不触发自动 JEV 完成判断。显式 `jev_decide` 仍可由 Agent 按需调用。

## 安全边界

- 所有网页动作继续使用现有动作白名单、活动标签绑定和串行执行队列，不执行任意脚本。
- 自动重试不重复执行结果不确定的非幂等动作；重试等待期间用户可以停止当前任务。
- JEV 只负责结构化判断，不执行浏览器动作；Token 继续只在主进程使用，不返回 renderer。
- 完成判断失败或响应缺少有效 `completed` 时，不宣称任务已完成。

## 可验证成功标准

1. 对话卡片会显示点击坐标、滚动参数、键盘按键等动作细节；空白区域坐标点击也展示相同格式。
2. 可恢复的模型请求、JEV 请求及工具失败会按 1、2、4、8、16 秒最多重试 5 次；成功后继续任务，停止或关闭窗口后不会再发起重试。
3. 点击、提交、上传等动作发生结果不明的超时时，系统会重新观察而不自动重复动作。
4. 网页任务每批动作后显示 JEV 完成判断、置信度和理由；未完成时 Agent 再次调用工具，完成时生成最终用户答复。
5. 超过步骤上限、JEV 无法判定或用户中止时，界面不会声称任务已经完成，并会显示可理解的原因。
6. 普通闲聊不会触发自动 JEV 判断；显式 `jev_decide` 仍可用。
