# 订阅行统计与名称编辑

## 目的

- 将订阅统计从整个订阅列表的共用区域移动到每个订阅行的中间位置，避免多个订阅共用一组无法对应的数据。
- 支持导入订阅时填写显示名称；未填写时从 HTTP(S) 订阅地址提取域名作为名称。
- 支持双击订阅名称后直接编辑并持久化名称。
- 统一节点信息表的单元格居中方式，并保证核心选择下拉控件可操作。

## 行为

- 每个订阅行显示四个独立统计块：剩余流量、到期时间、下次重置和可用节点数；统计值只来自该订阅。
- 导入请求的名称去除首尾空白并限制长度；名称为空时使用订阅 URL 的 hostname，无法解析 URL 时回退到现有默认名称。
- 刷新订阅保留用户已经设置的名称；旧记录仍使用通用默认名称时，首次刷新可补齐 URL 域名。
- 双击订阅名称进入单行编辑，按 Enter 或失焦保存，按 Escape 取消；空名称不保存并提示用户。
- 名称修改通过主进程 IPC 写入本地状态，不暴露订阅地址或访问令牌。
- 节点表标题、协议、地址、IP、核心、状态和操作内容在单元格内水平与垂直居中；核心下拉控件保持原生键盘和鼠标交互，不能被相邻网格列遮挡。

## 验证

- 测试订阅 URL hostname 提取、非法 URL 回退和名称长度/空白处理。
- 手动导入两个不同 URL 的订阅，确认每行四个统计块显示各自数据；分别双击改名并刷新应用，确认名称保留。
- 手动检查节点表各列居中，并点击核心下拉箭头完成切换。
- 运行 `npm test` 与 `npm run check`。
