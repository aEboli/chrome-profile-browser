# 代理核心更新提醒与订阅节点覆盖

## 目的

- 自动发现已配置 Xray-core、sing-box 或外部 Chromium 的官方新版本，并在管理页提醒用户。
- 让成功的订阅刷新以新节点列表为准，不保留旧订阅节点或旧的本地字段覆盖。

## 行为

- 应用启动时检查已配置核心，并按固定间隔再次检查；仅发现远端版本高于当前版本时发送提醒，不自动下载或替换核心。
- 已安装的外部 Chromium 使用官方稳定版清单检查；内置 Electron Chromium 随应用版本发布，不参与独立更新。
- 核心版本查询失败不改变当前核心状态，也不阻止应用启动和节点运行。
- 订阅成功解析出新节点后，删除该订阅之前的全部节点并写入本次结果；仍保留旧节点仅用于请求失败或没有可识别内容时的回退。
- 被新列表移除的节点如果仍被环境使用，会将该环境切回系统直连，避免引用已删除节点。

## 验证

- 核心更新器单元测试覆盖版本比较和仅查询版本的路径。
- 运行 `npm test` 与 `npm run check`。
- 启动管理页，确认有新核心版本时出现提醒；刷新订阅后确认旧节点字段不再覆盖新结果。
