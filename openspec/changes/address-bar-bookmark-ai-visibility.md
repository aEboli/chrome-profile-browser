# 地址栏收藏星标与独立 AI 入口

## 目标

让地址栏收藏控件保持稳定，并让网页助手入口独立于地址栏焦点。

## 行为

- 收藏按钮固定在地址输入框右侧，当前 HTTP(S) 地址未收藏时显示空心 `☆`，已收藏时显示 `⭐`；焦点变化不移动按钮。
- SVG `AI` 入口是地址栏外侧独立的工具栏按钮，始终可用。
- 收藏数据仍按 profile 持久化，导航、切换标签页和收藏栏继续复用现有状态。

## 验证

1. 打开未收藏的 HTTP(S) 页面，确认地址栏显示 `☆`；点击收藏后地址不清空且星标固定显示 `⭐`，再次点击可移除收藏。
2. 地址输入框聚焦和失焦时确认星标位置不变，AI 入口始终在地址栏外侧且可打开网页助手面板。
3. 切换标签页或导航后确认星标状态与当前 URL 的 profile 收藏数据一致。

状态：已实现并完成自动化验证。
